# Техническое задание

Необходимо полностью реализовать утилитарную функцию-декоратор Throttle по требованиям ниже, включая ВСЕ перечисленные
в структуре файлы.

## Структура:

```text
├── Throttle                                          # Каталог с именем утилиты
│   ├── tests                                         # Каталог с Unit-тестами
│   │   ├── Throttle.test.ts                          # Unit-тесты главной утилиты
│   ├── types                                         # Каталог с типами директивы
│   │   ├── Throttle.enum.ts                          # Enum утилиты
│   │   ├── Throttle.types.ts                         # Типы утилиты
│   ├── Throttle.ts                                   # Основной (входной) файл элемента
│   ├── Throttle.d.ts                                 # Основной файл с типами элемента
```

## Утилита Throttle
Техническое задание для утилиты Throttle:

1. Назначение
   * Утилита `Throttle` предназначена для ограничения частоты вызова функции. Это полезно в случаях, когда необходимо
   предотвратить слишком частые вызовы функции, например, при обработке событий прокрутки, изменения размера окна или
   ввода данных от пользователя. Утилита гарантирует, что функция будет вызываться не чаще, чем указанный интервал
   времени.
2. Общие требования:
   * Утилита должна поддерживать SSR.
   * Код должен быть модульным и легко интегрируемым в существующую кодовую базу.
   * Утилита должна быть совместима с современными браузерами и поддерживать основные среды выполнения JavaScript.
3. Функциональные требования
   1. Параметры функции:
      * `callback`: Функция, вызов которой необходимо ограничить. Обязательный параметр.
      * `timeout`: Интервал времени (в миллисекундах), в течение которого функция не может быть вызвана повторно. По 
      умолчанию 300 мс.
   2. Поведение:
      * Если `callback` не является функцией, утилита должна выбрасывать ошибку с соответствующим сообщением.
      * Утилита должна возвращать новую функцию, которая может быть вызвана с произвольным количеством аргументов.
      * Если функция вызывается повторно до истечения интервала `timeout`, новый вызов должен быть проигнорирован.
      * После истечения интервала `timeout`, функция `callback` должна быть вызвана с последними переданными аргументами.
4. Требования к тестированию:
   * Покрыть директиву unit-тестами:
5. Требования к документации:
   * Типы должны находится в отдельном файле `Throttle.d.ts`;
   * Описание сценариев применения утилиты.
