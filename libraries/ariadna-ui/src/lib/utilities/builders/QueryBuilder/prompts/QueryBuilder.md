Необходимо полностью реализовать утилитарную функцию QueryBuilder по требованиям ниже, включая ВСЕ перечисленные
в структуре файлы.


## Утилита QueryBuilder
Техническое задание для утилиты QueryBuilder:

1. Назначение
   * Утилита `QueryBuilder` предназначена для удобного и типобезопасного построения и управления параметрами 
   URL-запросов. Она позволяет создавать, изменять, удалять и очищать параметры запроса, а также формировать строку 
   запроса и объект параметров для дальнейшего использования в приложении.
2. Общие требования:
   * Утилита должна поддерживать SSR.
   * Утилита должна быть независимой и не иметь внешних побочных эффектов.
   * Интерфейс утилиты должен обеспечивать цепочку вызовов (chaining) для удобства использования.
3. Функциональные требования
   1. Конструктор должен принимать начальный объект параметров, поддерживающий `string`, `null`, `undefined` и 
   `Array<string>`.
   1. Методы класса:
      * `setParam(name, value)`— устанавливает одиночный параметр с возможностью значения `string`, `null` или 
      `undefined`.
      * `setArrayParam(name, values)` — устанавливает параметр с массивом строк, `null` или `undefined`.
      * `deleteParams(keys)` — удаляет указанные параметры из текущего набора.
      * `clearQuery()` — удаляет параметры с пустыми значениями: пустая строка, `null`, `undefined` или пустой массив.
      * `removeQuery()` — полностью очищает все параметры и возвращает `undefined`.
      * `buildQueryString()` — формирует query строку из текущих параметров.
      * `buildQueryObject()` — формирует query объект из текущих параметров.

5. Требования к документации:
   * Типы должны находится в отдельном файле `QueryBuilder.d.ts`;
   * Описание сценариев применения утилиты.
