# Техническое задание

Необходимо полностью реализовать Vue 3 компонент Spinner.vue по требованиям ниже, включая ВСЕ перечисленные в структуре
файлы.

## Структура:

```text
├── Spinner                             # Каталог с именем компонента
│   ├── composables                     # Каталог с описанием реактивной функциональности компонента (Vue 3)
│   │   ├── useSpinner                  # Каталог с composable useSpinner
│   │   │   ├── useSpinner.ts           # Composable useSpinner
│   │   │   ├── useSpinner.types.ts     # Типы composable useSpinner
│   ├── tests                           # Каталог с Unit-тестами компонента
│   │   ├── components                  # Каталог с Unit-тестами для компонентов
│   │   │   ├── Spinner.test.ts         # Unit-тесты главного компонента
│   │   ├── composables                 # Каталог с Unit-тестами для composables
│   │   │   ├── useSpinner.test.ts      # Unit-тесты composable useSpinner
│   ├── types                           # Каталог с типами компонента
│   ├── Spinner.vue                     # Основной (входной) файл элемента
│   ├── Spinner.d.ts                    # Основной файл с типами элементов
```

## Компонент Spinner.vue
Техническое задание для компонента `Spinner.vue`:

1. Назначение
   * Компонент `Spinner.vue` предназначен для визуального отображения процесса загрузки или выполнения операции. Он 
   используется для индикации пользователю, что система выполняет какую-либо задачу, например, загрузку данных или 
   обработку запроса.
2. Общие требования:
  * Компонент должен поддерживать SSR.
  * Использование Composition API + `<script setup>`.
  * Prop типизация через `defineProps<T>()`.
  * Slots типизация через `defineSlots<T>()`.
  * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
  * Реактивный функционал должен быть реализован в composable `useSpinner`.
  * Компонент должен отображать анимацию загрузки.
  * Компонент должен поддерживать различные размеры (`small`, `medium`, `large`). 
  * Компонент должен поддерживать модификаторы для изменения внешнего вида (например, `primary`, `secondary`). 
  * Компонент должен быть доступен для кастомизации через слоты, если необходимо добавить дополнительный контент.
4. Пропсы:
  * `size` (тип: `TSpinnerPropsSize`, по умолчанию: `'medium'`): Определяет размер компонента.
  * `cssClass` (тип: `string`, по умолчанию: `'ar-spinner'`): CSS класс для корневого элемента.
  * `modifier` (тип: `TSharedPropsModifier`, по умолчанию: `undefined`): Модификатор базового CSS класса.
5. Слоты:
  * `default`: Слот для добавления дополнительного контента внутри компонента, если это необходимо.
6. События:
  * Отсутствуют.
7. Требования к стилям:
  * Отсутствуют.
8. Требования к тестированию:
  * Покрыть компонент unit-тестами:
9. Требования к документации:
  * Типы должны находится в отдельном файле `Spinner.d.ts`;
  * Добавить TSDoc-комментарии к типам, компоненту и composable.
