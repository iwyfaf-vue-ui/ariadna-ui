# Техническое задание

Необходимо полностью реализовать Vue 3 компонент Badge.vue по требованиям ниже, включая ВСЕ перечисленные в структуре
файлы.

## Структура:

```text
├── Badge                               # Каталог с именем компонента
│   ├── composables                     # Каталог с описанием реактивной функциональности компонента (Vue 3)
│   │   ├── useBadge                    # Каталог с composable useBadge
│   │   │   ├── useBadge.ts             # Composable useBadge
│   │   │   ├── useBadge.types.ts       # Типы composable useBadge
│   ├── tests                           # Каталог с Unit-тестами компонента
│   │   ├── Badge.test.ts               # Unit-тесты главного компонента
│   │   ├── useBadge.test.ts            # Unit-тесты composable useBadge
│   ├── types                           # Каталог с типами компонента
│   ├── Badge.vue                       # Основной (входной) файл элемента
│   ├── Badge.d.ts                      # Основной файл с типами элементов
```

## Компонент Badge.vue
Техническое задание для компонента `Badge.vue`:

1. Назначение
   * Компонент `Badge.vue` представляет собой небольшой индикатор статуса, который может использоваться для отображения
   уведомлений, меток или других информационных элементов. Он должен быть гибким и легко настраиваемым для 
   использования в различных сценариях интерфейса.
2. Общие требования:
  * Компонент должен поддерживать SSR.
  * Использование Composition API + `<script setup>`.
  * Prop типизация через `defineProps<T>()`.
  * Slots типизация через `defineSlots<T>()`.
  * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
  * Реактивный функционал должен быть реализован в composable `useBadge`.
  * Компонент должен поддерживать различные размеры (`small`, `medium`, `large`).
  * Должна быть возможность задавать закругленные углы (`rounded`).
  * Должна быть возможность задавать плавающее положение (`floating`).
  * Должна быть возможность задавать дополнительные CSS классы для кастомизации внешнего вида.
  * Компонент должен поддерживать модификаторы базового CSS класса.
4. Пропсы:
  * `size` (тип: `TBadgePropsSize`, по умолчанию: `'medium'`): Размер бейджа.
  * `rounded` (тип: `boolean`, по умолчанию: `false`): Закругленные углы бейджа.
  * `floating` (тип: `boolean`, по умолчанию: `false`): Плавающее положение бейджа.
  * `cssClass` (тип: `string`, по умолчанию: `'ar-badge'`): CSS класс для корневого элемента.
  * `modifier` (тип: `TSharedPropsModifier`, по умолчанию: `undefined`): Модификатор базового CSS класса.
5. Слоты:
  * `default`: Слот для основного содержимого бейджа (текст).
6. События:
  * Отсутствуют.
7. Требования к стилям:
  * Отсутствуют.

  * Покрыть компонент unit-тестами:
9. Требования к документации:
  * Типы должны находится в отдельном файле `Badge.d.ts`;
  * Добавить TSDoc-комментарии к типам, компоненту и composable.
