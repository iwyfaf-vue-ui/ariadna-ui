Реализуй Vue 3 компонент Badge.vue по требованиям ниже.

1. Структура:

├── Badge                               # Каталог с именем компонента
│   ├── composables                     # Каталог с описанием реактивной функциональности компонента (Vue 3)
│   │   ├── useBadge                    # Каталог с composable useBadge
│   │   │   ├── useBadge.ts             # Composable useBadge
│   │   │   ├── useBadge.types.ts       # Типы composable useBadge
│   ├── tests                           # Каталог с Unit-тестами компонента
│   │   ├── Badge.test.ts               # Unit-тесты главного компонента
│   │   ├── useBadge.test.ts            # Unit-тесты composable useBadge
│   ├── types                           # Каталог с типами компонента
│   ├── Badge.vue                       # Основной (входной) файл элемента
│   ├── Badge.d.ts                      # Основной файл с типами элементов

2. Props
    1. size
        1. Компонент должен уметь менять свои размеры с помощью props size;
        2. К корневому элементу должны добавляться CSS-модификаторы:
            - --small
            - --medium
            - --large
    2. rounded
        1. props rounded должен добавлять к корневому элементу CSS-модификатор `--rounded`;
    3. floating
        1. Компонент должен иметь состояние floating. Определяет, должен ли Badge перемещаться в правую верхнюю часть
        относительно родительского элемента или нет (через CSS).
        2. props floating должен добавлять к корневому элементу CSS-модификатор `--floating`;
    4. cssClass
        1. Компонент должен уметь базовый CSS класс с помощью props cssClass;
        2. props cssClass должен переопределять всю структуру стилей компонента;
    5. modifier
        1. Компонент должен уметь применять CSS класс-модификатор modifier;
        2. props modifier должен добавлять к корневому элементу CSS-модификатор `--значение props modifier`;

3. Slots
    1. default
        1. Компонент должен иметь слот default для вывода текста кнопки;
        2. Компонент не должен выводить HTML-контейнер слота, если слот - пустой;

4. Требования к реализации компонента:
    1. Общие требования:
        * Типы должны находится в отдельном файле Button.d.ts;
        * Использование Composition API + `<script setup>`;
        * Prop типизация через `defineProps<T>()`;
        * Slots типизация через `defineSlots<T>()`;
        * Emits типизация через `defineEmits<T>()`;
        * Реактивная логика должна быть реализована в каталоге composables;
        * Нереактивная логика должна быть реализована в каталоге core.

5. Примеры
    1. Пример генерации CSS-стилей компонента:

        const componentClasses = computed(() => {
            const base = props.cssClass;

            const theme = `${base}--theme`;
            const size = props.size ? `${base}--${props.size}` : undefined;
            const modifier = props.modifier ? `${base}--${props.modifier}` : undefined;

            return [
              base,
              theme,
              size,
              modifier,
            ]
              .filter(Boolean)
              .join(' ');
          });
