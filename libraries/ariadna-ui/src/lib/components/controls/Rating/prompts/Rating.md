## Компонент Rating.vue
Техническое задание для компонента Rating:

1. Назначение
    * Компонент предназначен для отображения и выбора рейтинга в виде набора звёзд (или других иконок). Пользователь 
   может выставить оценку, увидеть текущий рейтинг, сбросить его, а также просмотреть возможные ошибки или подсказки.
2. Общие требования:
    * Компонент должен поддерживать SSR.
    * Использование Composition API + `<script setup>`.
    * Prop типизация через `defineProps<T>()`.
    * Slots типизация через `defineSlots<T>()`.
    * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
    * Реактивный функционал должен быть реализован в composable `useRating`.
    * Отображение заданного количества звёзд (по умолчанию 5).
    * Возможность выбора значения рейтинга с заданным шагом (например, 0.5, 1).
    * Отображение текущего значения рейтинга.
    * Возможность сброса значения рейтинга (если включено).
    * Кастомизация отображения отдельных элементов через слоты (звёзды, значение, сброс, ошибки).
    * Поддержка различных позиций отображения значения рейтинга (сверху, снизу, слева, справа от звёзд).
    * Отображение ошибок валидации с анимацией.
4. Пропсы:
    * `modelValue: number` — текущее значение рейтинга (обязательный, v-model).
    * `label?: string` — подпись к рейтингу.
    * `id?: string` — идентификатор для связывания с `label`.
    * `starCount?: number` — количество звёзд (по умолчанию `5`).
    * `fillStep?: number` — шаг заполнения (например, `1` или `0.5`).
    * `singleMode?: boolean` — вывод одиночной звезды (например, `1` или `0.5`).
    * `size?: TSharedPropsSize` — размер звёзд.
    * `showValue?: boolean` — отображать ли текущее значение рейтинга.
    * `valuePosition?: TRatingPropsValuePosition` — позиция отображения значения рейтинга.
    * `reset?: boolean` — отображать ли кнопку сброса.
    * `disabled?: boolean` — отключить взаимодействие.
    * `readonly?: boolean` — только для просмотра.
    * `valid?: boolean` — состояние "валидно".
    * `invalid?: boolean` — состояние "невалидно".
    * `errors?: string[]` — массив сообщений об ошибках.
    * `cssClass?: string` (по умолчанию `'ar-rating'`)
    * `modifier` (тип: `TSharedPropsModifier`, по умолчанию: `undefined`): Модификатор базового CSS класса.
5. Слоты:
    * `active` — кастомизация активной (выбранной) звезды.
    * `inactive` — кастомизация неактивной звезды.
    * `value` — кастомизация отображения значения рейтинга `(props: { value, starCount })`.
    * `reset` — кастомизация кнопки сброса `(props: { reset })`.
    * `errors` — кастомизация отображения ошибок `(props: { errors })`.
6. События:
   * `update:model-value` — эмитится при изменении значения рейтинга (`v-model`).
   * `focus` — эмитится при получении фокуса компонентом.
