# Техническое задание

Необходимо полностью реализовать Vue 3 компонент Checkbox.vue по требованиям ниже, включая ВСЕ перечисленные в
структуре файлы.

## Структура:

```text
├── Checkbox                                          # Каталог с именем компонента
│   ├── composables                                   # Каталог с описанием реактивной функциональности компонента (Vue 3)
│   │   ├── useCheckbox                               # Каталог с composable useCheckbox
│   │   │   ├── useCheckbox.ts                        # Composable useCheckbox
│   │   │   ├── useCheckbox.types.ts                  # Типы composable useCheckbox
│   ├── tests                                         # Каталог с Unit-тестами компонента
│   │   ├── components                                # Каталог с Unit-тестами для компонентов
│   │   │   ├── Checkbox.test.ts                      # Unit-тесты главного компонента
│   │   ├── composables                               # Каталог с Unit-тестами для composables
│   │   │   ├── useCheckbox.test.ts                   # Unit-тесты composable useCheckbox
│   ├── types                                         # Каталог с типами компонента
│   │   ├── Checkbox.enums.ts                         # Enums компонента со значениями props по умолчанию
│   │   ├── Checkbox.types.ts                         # Types компонента
│   ├── Checkbox.vue                                  # Основной (входной) файл элемента
│   ├── Checkbox.d.ts                                 # Основной файл с типами элементов
```

## Компонент Checkbox.vue
Техническое задание для компонента Checkbox:

1. Назначение
    * Компонент Checkbox предназначен для отображения и управления состоянием чекбокса с поддержкой кастомного 
   оформления, валидации, отображения ошибок и расширенной работы со слотами.
2. Общие требования:
    * Компонент должен поддерживать SSR.
    * Использование Composition API + `<script setup>`.
    * Prop типизация через `defineProps<T>()`.
    * Slots типизация через `defineSlots<T>()`.
    * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
    * Реактивный функционал должен быть реализован в composable `useCheckbox`.
    * Отображение стандартного или кастомного чекбокса.
    * Отображение ошибок валидации с анимацией.
4. Пропсы*:*
    * `modelValue: boolean` — текущее состояние чекбокса (выбран/не выбран).
    * `id (string | undefined)`: `id` атрибут `textarea` (по умолчанию генерируется).
    * `name: string` — имя чекбокса (атрибут `name`).
    * `disabled: boolean` — отключение чекбокса.
    * `size: TSharedPropsSize` — размер чекбокса (например, `small`, `medium`, `large`).
    * `position: TCheckboxPropsType` — положение чекбокса относительно контента.
    * `custom: boolean` — использовать ли кастомный вид чекбокса.
    * `valid (boolean | undefined)`: Состояние валидности поля (по умолчанию `false`).
    * `invalid (boolean | undefined)`: Состояние невалидности поля (по умолчанию `false`).
    * `errors (Array<string>)`: Список ошибок для отображения (по умолчанию `[]`).
    * `cssClass (string)`: CSS-класс для стилизации (по умолчанию `ar-textarea`).
    * `modifier` (тип: `TSharedPropsModifier`, по умолчанию: `undefined`): Модификатор базового CSS класса.
    * `ariaLabel: string` — aria-label для лучшей доступности.
5. Слоты:
    * `default` — контент, отображаемый рядом с чекбоксом (например, подпись).
    * `custom` — слот для кастомного отображения чекбокса.
    * `errors` — слот для кастомного отображения ошибок (получает проп errors).
6. События:
   * `update:modelValue` — эмитится при изменении значения чекбокса.
   * `focus` — эмитится при получении фокуса.
   * `blur` — эмитится при потере фокуса.
   * `change` — эмитится при изменении значения.
7. Требования к стилям:
    * Отсутствуют.

9. Требования к документации:

    * Добавить TSDoc-комментарии к типам, компоненту и composable.
