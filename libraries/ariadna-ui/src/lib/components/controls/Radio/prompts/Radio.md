# Техническое задание

Необходимо полностью реализовать Vue 3 компонент Radio.vue по требованиям ниже, включая ВСЕ перечисленные в
структуре файлы.

## Структура: 

```text
├── Radio                                             # Каталог с именем компонента
│   ├── composables                                   # Каталог с описанием реактивной функциональности компонента (Vue 3)
│   │   ├── useRadio                                  # Каталог с composable useRadio
│   │   │   ├── useRadio.ts                           # Composable useRadio
│   │   │   ├── useRadio.types.ts                     # Типы composable useRadio
│   ├── tests                                         # Каталог с Unit-тестами компонента
│   │   ├── components                                # Каталог с Unit-тестами для компонентов
│   │   │   ├── Radio.test.ts                         # Unit-тесты главного компонента
│   │   ├── composables                               # Каталог с Unit-тестами для composables
│   │   │   ├── useRadio.test.ts                      # Unit-тесты composable useRadio
│   ├── types                                         # Каталог с типами компонента

│   ├── Radio.d.ts                                    # Основной файл с типами элементов
```

## Компонент Radio.vue
Техническое задание для компонента Radio:

1. Назначение
   * Компонент предназначен для отображения и управления элементом выбора одного значения из группы (radio button) с 
   возможностью кастомизации внешнего вида.
2. Общие требования:
  * Компонент должен поддерживать SSR.
  * Использование Composition API + `<script setup>`.
  * Prop типизация через `defineProps<T>()`.
  * Slots типизация через `defineSlots<T>()`.
  * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
  * Реактивный функционал должен быть реализован в composable `useRadio`.
  * Отображение стандартного или кастомного radio.
  * Отображение ошибок валидации с анимацией.
4. Пропсы:
  * `modelValue: any` — текущее состояние радио-кнопки.
  * `value: any` — текущее значение радио-кнопки.
  * `id (string | undefined)`: `id` атрибут `<input type="radio"` (по умолчанию генерируется).
  * `name: string` — имя радио-кнопки (атрибут `name`).
  * `disabled: boolean` — отключение радио-кнопки.
  * `size: TSharedPropsSize` — размер радио-кнопки (например, `small`, `medium`, `large`).
  * `position: TRadioPropsType` — положение радио-кнопки относительно контента.
  * `custom: boolean` — использовать ли кастомный вид радио-кнопки.
  * `valid (boolean | undefined)`: Состояние валидности поля (по умолчанию `false`).
  * `invalid (boolean | undefined)`: Состояние невалидности поля (по умолчанию `false`).
  * `cssClass (string)`: CSS-класс для стилизации (по умолчанию `ar-radio`).
  * `modifier` (тип: `TSharedPropsModifier`, по умолчанию: `undefined`): Модификатор базового CSS класса.
5. Слоты:
  * `default` — контент, отображаемый рядом с радио-кнопкой (например, подпись).
  * `custom` — слот для кастомного отображения радио-кнопки.
6. События:
  * `update:modelValue` — эмитится при изменении значения `<input type="radio"`>.
  * `focus` — эмитится при получении фокуса.
  * `blur` — эмитится при потере фокуса.
  * `change` — эмитится при изменении значения.
7. Требования к стилям:
  * Отсутствуют.
8. Требования к тестированию:
  * Покрыть компонент unit-тестами:
9. Требования к документации:
  * Типы должны находится в отдельном файле `Radio.d.ts`;
  * Добавить TSDoc-комментарии к типам, компоненту и composable.
  * Описание сценариев применения компонента.
