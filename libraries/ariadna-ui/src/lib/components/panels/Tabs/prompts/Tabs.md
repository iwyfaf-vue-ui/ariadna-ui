## Компонент Tabs.vue
Техническое задание для компонента Tabs:

1. Назначение
    * Компонент `Tabs` предназначен для организации переключения между несколькими вкладками (табами), каждая из 
   которых отображает свой контент. Позволяет пользователю удобно переключаться между разными представлениями или 
   разделами интерфейса.
2. Общие требования:
    * Компонент должен поддерживать SSR.
    * Использование Composition API + `<script setup>`.
    * Prop типизация через `defineProps<T>()`.
    * Slots типизация через `defineSlots<T>()`.
    * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
    * Реактивный функционал должен быть реализован в composable `useTabs`.
    * Отображение списка вкладок с заголовками.
    * Возможность переключения активной вкладки по клику, клавишам Enter, Space, стрелкам влево/вправо.
    * Поддержка установки вкладки, открытой по умолчанию, через индекс или ключ.
    * Эмитирование события при смене активной вкладки с передачей ключа и данных вкладки.
    * Поддержка кастомных слотов для заголовков и содержимого вкладок.
    * Поддержка скользящего (slide) режима для заголовков вкладок с плавной анимацией.
4. Пропсы:
    * `tabs: Array<TTabItem>` — массив объектов вкладок (обязательный).
    * `openedByDefault?: number` — индекс вкладки, открытой по умолчанию (по умолчанию `0`).
    * `activeKeyByDefault?: string` — ключ вкладки, открытой по умолчанию (приоритетнее `openedByDefault`).
    * `titleKey?: string` — ключ в объекте вкладки, используемый для отображения заголовка (по умолчанию `ETabsPropsDefault.TITLE_KEY`).
    * `slide?: boolean` — включение режима скольжения заголовков (по умолчанию `false`).
    * `cssClass?: string` — базовый CSS класс для компонента (по умолчанию `ETabsPropsDefault.CSS_CLASS`).
    * `modifier?: TSharedPropsModifier` — модификатор CSS класса для стилизации.
5. Слоты:
    * `label-{index}` — слот для кастомного рендеринга заголовка вкладки с параметрами:
      * `item` — объект вкладки.
      * `selected` — булево значение, активна ли вкладка.
    * `default-{index}` — слот для кастомного рендеринга содержимого вкладки с параметром:
      * `item` — объект вкладки.
6. События:
   * `change` — событие, эмитируемое при смене активной вкладки, с полезной нагрузкой:
     * `key: string` — ключ выбранной вкладки.
     * `tab: TTabItem` — объект выбранной вкладки.
