структуре файлы.

## Компонент Accordion.vue
Техническое задание для компонента Accordion:

1. Назначение
    * Компонент Accordion предназначен для контейнерезации компонента AccordionItem.
2. Общие требования:
    * Компонент должен поддерживать SSR.
    * Использование Composition API + `<script setup>`.
    * Prop типизация через `defineProps<T>()`.
    * Slots типизация через `defineSlots<T>()`.
    * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
    * Реактивный функционал должен быть реализован в composable `useAccordion`.
    * Компонент должен отображать заголовок и содержимое.
    * Поддержка раскрытия и скрытия содержимого по клику или клавиатурным событиям.
    * Возможность управления состоянием открытия извне через пропсы.
    * Поддержка режима одиночного раскрытия (если компонент используется в группе).
    * Возможность отключения взаимодействия.
    * Обеспечение правильной работы с клавиатурой (Enter, Space, Esc, стрелки).
    * Поддержка анимаций при раскрытии/скрытии содержимого.
    * Предоставление методов для программного управления состоянием (открыть, закрыть, переключить).
4. Пропсы:
    * `singleMode (boolean, default: false)` — раскрытие не более одного элемента аккордеона.
    * `opened (boolean, default: false)` — состояние раскрытия аккордеона.
    * `clickableHeader (boolean, default: true)` — кликабельный заголовок аккордеона.
    * `disabled (boolean, default: false)` — блокировка взаимодействия.
    * `cssClass (string, optional, default: EAccordionPropsDefault.CSS_CLASS)` — дополнительный CSS класс для корневого
   элемента.
    * `modifier (TSharedPropsModifier, optional)` — модификатор для BEM-стилей.
5. Слоты:
    * `default` — основной контент аккордеона.
6. Требования к стилям:
    * Отсутствуют.
7. Требования к тестированию:
    * Покрыть компонент unit-тестами:
8. Требования к документации:
    * Типы должны находится в отдельном файле `Accordion.d.ts`;
    * Добавить TSDoc-комментарии к типам, компоненту и composable.
    * Описание сценариев применения компонента.
