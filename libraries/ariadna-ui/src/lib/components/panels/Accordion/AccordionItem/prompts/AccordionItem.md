структуре файлы.

## Компонент Accordion.vue
Техническое задание для компонента AccordionItem:

1. Назначение
    * Компонент AccordionItem предназначен для отображения интерактивного элемента пользовательского интерфейса, 
   который позволяет пользователю раскрывать и скрывать содержимое внутри компонента Accordion.
2. Общие требования:
    * Компонент должен поддерживать SSR.
    * Использование Composition API + `<script setup>`.
    * Prop типизация через `defineProps<T>()`.
    * Slots типизация через `defineSlots<T>()`.
    * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
    * Реактивный функционал должен быть реализован в composable `useAccordionItem`.
    * Компонент должен управлять состоянием раскрытия (открыт/закрыт).
    * Поддерживать блокировку взаимодействия через пропс `disabled`.
    * Обеспечивать доступность (accessibility) с помощью атрибутов aria.
    * Поддерживать кастомизацию заголовка и элемента управления раскрытием через слоты.
    * Предоставлять методы для программного управления состоянием (открыть, закрыть, переключить).
    * Обеспечивать корректную работу с клавиатурой (обработка событий клавиш).
4. Пропсы:
    * `opened (boolean, default: false)` — состояние раскрытия элемента аккордеона.
    * `disabled (boolean, default: false)` — блокировка взаимодействия.
    * `ariaLabel (string, optional)` — описание для accessibility.
5. Слоты:
    * `default` — основной контент аккордеона.
    * `header` — кастомный заголовок, получает параметр `opened (boolean)`.
    * `activator` — элемент управления раскрытием, получает параметры `opened`, `open()`, `close()`, `toggle()`.
6. События:
   * `change` — эмитится при изменении состояния раскрытия, передает новое значение (`boolean`).
   * `focus` — эмитится при получении фокуса, передает объект события.
   * `blur` — эмитится при потере фокуса, передает объект события.
7. Требования к стилям:
    * Отсутствуют.
8. Требования к тестированию:
    * Покрыть компонент unit-тестами:
9. Требования к документации:
    * Типы должны находится в отдельном файле `AccordionItem.d.ts`;
    * Добавить TSDoc-комментарии к типам, компоненту и composable.
    * Описание сценариев применения компонента.
