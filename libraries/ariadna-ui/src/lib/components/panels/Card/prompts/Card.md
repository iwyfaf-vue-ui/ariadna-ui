# Техническое задание

Необходимо полностью реализовать Vue 3 компонент Card.vue по требованиям ниже, включая ВСЕ перечисленные в
структуре файлы.

## Структура:

```text
├── Card                                              # Каталог с именем компонента
│   ├── composables                                   # Каталог с описанием реактивной функциональности компонента (Vue 3)
│   │   ├── useCard                                   # Каталог с composable useCard
│   │   │   ├── useCard.ts                            # Composable useCard
│   │   │   ├── useCard.types.ts                      # Типы composable useCard
│   ├── tests                                         # Каталог с Unit-тестами компонента
│   │   ├── components                                # Каталог с Unit-тестами для компонентов
│   │   │   ├── Card.test.ts                          # Unit-тесты главного компонента
│   │   ├── composables                               # Каталог с Unit-тестами для composables
│   │   │   ├── useCard.test.ts                       # Unit-тесты composable useCard
│   ├── types                                         # Каталог с типами компонента
│   │   ├── Card.enums.ts                             # Enums компонента со значениями props по умолчанию
│   │   ├── Card.types.ts                             # Types компонента
│   ├── Card.vue                                      # Основной (входной) файл элемента
│   ├── Card.d.ts                                     # Основной файл с типами элементов
```

## Компонент Card.vue
Техническое задание для компонента Card:

1. Назначение
    * Card — универсальный контейнерный компонент для отображения информации в виде карточки с поддержкой кастомизации
   содержимого через слоты и управления состоянием сворачивания основного контента.
2. Общие требования:
    * Компонент должен поддерживать SSR.
    * Использование Composition API + `<script setup>`.
    * Prop типизация через `defineProps<T>()`.
    * Slots типизация через `defineSlots<T>()`.
    * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
    * Реактивный функционал должен быть реализован в composable `useCard`.
    * Компонент должен поддерживать динамическое изменение HTML-тега корневого элемента через пропс.
    * Управление состоянием сворачивания основного контента на основе пропса `symbols` (если `all` > `visible`, контент сворачивается).
    * Анимация сворачивания/разворачивания основного контента с помощью Vue `<Transition>`.
    * Передача состояния и методов управления сворачиванием в слоты `content` и `contentFooter`.
4. Пропсы:
    * `tag (TCardPropsTag, по умолчанию 'ECardPropsDefault.TAG')`: HTML-тег корневого элемента.
    * `symbols `(`TCardPropsSymbols`, по умолчанию `{ all: 0, visible: 0 }`): параметры для управления сворачиванием контента.
    * `cssClass?: string` (по умолчанию `ECardPropsDefault.CSS_CLASS`)
    * `modifier` (тип: `TSharedPropsModifier`, по умолчанию: `undefined`): Модификатор базового CSS класса.
5. Слоты:
    * `picture`: слот для изображения или иконки в карточке.
    * `contentHeader`: слот для кастомного контента в шапке основной области.
    * `content (props: { isCollapsed: boolean, toggleCollapsed: () => void })`: основной контент карточки, с поддержкой управления сворачиванием.
    * `contentFooter (props: { isCollapsed: boolean, toggleCollapsed: () => void })`: дополнительный контент внизу основной области, с поддержкой управления сворачиванием.
    * `footer`: слот для футера карточки.
6. Требования к стилям:
    * Отсутствуют.
7. Требования к тестированию:
    * Покрыть компонент unit-тестами:
8. Требования к документации:
    * Типы должны находится в отдельном файле `Card.d.ts`;
    * Добавить TSDoc-комментарии к типам, компоненту и composable.
    * Описание сценариев применения компонента.
