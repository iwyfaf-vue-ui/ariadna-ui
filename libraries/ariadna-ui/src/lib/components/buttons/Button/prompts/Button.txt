Реализуй Vue 3 компонент Button.vue по требованиям ниже.

Требования к работе компонента:

1. Структура:

├── Button                              # Каталог с именем компонента
│   ├── composables                     # Каталог с описанием реактивной функциональности компонента (Vue 3)
│   │   ├── useButton                   # Каталог с composable useButton
│   │   │   ├── useButton.ts            # Composable useButton
│   │   │   ├── useButton.types.ts      # Типы composable useButton
│   ├── tests                           # Каталог с Unit-тестами компонента
│   │   ├── Button.test.ts              # Unit-тесты главного компонента
│   │   ├── useButton.test.ts           # Unit-тесты composable useButton
│   ├── types                           # Каталог с типами компонента
│   ├── Button.vue                      # Основной (входной) файл элемента
│   ├── Button.d.ts                     # Основной файл с типами элементов

2. Props
    1. Tag
        1. Компонент должен уметь рендерить тег button, span и a;
    2. type
        1. Компонент должен позволять указывать props type только если кнопка рендерится как элемент button;
    3. iconPosition
        1. Компонент должен уметь менять позицию иконки с помощью props iconPosition;
        2. К корневому элементу должны добавляться CSS-модификаторы:
            - --icon-left
            - --icon-top
            - --icon-right
            - --icon-bottom
    4. size
        1. Компонент должен уметь менять свои размеры с помощью props size;
        2. К корневому элементу должны добавляться CSS-модификаторы:
            - --small
            - --medium
            - --large
    5. rounded
        1. props rounded должен добавлять к корневому элементу CSS-модификатор `--rounded`;
    6. textual
        1. props textual должен добавлять к корневому элементу CSS-модификатор `--textual`;
    7. outlined
        1. props outlined должен добавлять к корневому элементу CSS-модификатор `--outlined`;
    8. selected
        1. Компонент должен иметь состояние selected;
        1. props selected должен добавлять к корневому элементу CSS-модификатор `--selected`;
    9. disabled
        1. Компонент должен иметь состояние disabled;
        1. props disabled должен добавлять к корневому элементу CSS-модификатор `--disabled`;
    10. loading
        1. Компонент должен иметь состояние loading;
        1. props loading должен добавлять к корневому элементу CSS-модификатор `--loading`;
    11. cssClass
        1. Компонент должен уметь базовый CSS класс с помощью props cssClass;
        2. props cssClass должен переопределять всю структуру стилей компонента;
    12. modifier
        1. Компонент должен уметь применять CSS класс-модификатор modifier;
        2. props modifier должен добавлять к корневому элементу CSS-модификатор `--значение props modifier`;
3. Slots
    1. default
        1. Компонент должен иметь слот default для вывода текста кнопки;
        2. Компонент не должен выводить HTML-контейнер слота, если слот - пустой;
    2. icon
        1. Компонент должен иметь слот icon для вывода иконки кнопки;
        2. Компонент не должен выводить HTML-контейнер слота, если слот - пустой;
    3. loading
        1. Компонент должен иметь слот loading для вывода загрузки кнопки;
        2. Компонент не должен выводить HTML-контейнер слота, если слот - пустой и если props loading неактивен;
4. Emits
    1. Компонент должен эмитить событие click;

5. Требования к реализации компонента:
    1. Общие требования:
        * Типы должны находится в отдельном файле Button.d.ts;
        * Использование Composition API + `<script setup>`;
        * Prop типизация через `defineProps<T>()`;
        * Slots типизация через `defineSlots<T>()`;
        * Emits типизация через `defineEmits<T>()`;
        * Реактивная логика должна быть реализована в каталоге composables;
        * Нереактивная логика должна быть реализована в каталоге core.

6. Примеры
    1. Пример генерации CSS-стилей компонента:

        const componentClasses = computed(() => {
            const base = props.cssClass;

            const theme = `${base}--theme`;
            const size = props.size ? `${base}--${props.size}` : undefined;
            const disabled = isDisabled.value ? `${base}--disabled` : undefined;
            const loading = props.loading ? `${base}--loading` : undefined;
            const modifier = props.modifier ? `${base}--${props.modifier}` : undefined;

            return [
              base,
              theme,
              size,
              disabled,
              loading,
              modifier,
            ]
              .filter(Boolean)
              .join(' ');
          });
