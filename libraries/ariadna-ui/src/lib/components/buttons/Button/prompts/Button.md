# Техническое задание

Необходимо полностью реализовать Vue 3 компонент Button.vue по требованиям ниже, включая ВСЕ перечисленные в структуре
файлы.

## Структура:

```text
├── Button                              # Каталог с именем компонента
│   ├── composables                     # Каталог с описанием реактивной функциональности компонента (Vue 3)
│   │   ├── useButton                   # Каталог с composable useButton
│   │   │   ├── useButton.ts            # Composable useButton
│   │   │   ├── useButton.types.ts      # Типы composable useButton
│   ├── tests                           # Каталог с Unit-тестами компонента
│   │   ├── Button.test.ts              # Unit-тесты главного компонента
│   │   ├── useButton.test.ts           # Unit-тесты composable useButton
│   ├── types                           # Каталог с типами компонента
│   ├── Button.vue                      # Основной (входной) файл элемента
│   ├── Button.d.ts                     # Основной файл с типами элементов
```

## Компонент Button.vue
Техническое задание для компонента `Button.vue`:

1. Назначение
   * Компонент `Button.vue` представляет собой кнопку с поддержкой различных состояний, иконок, размеров и стилей. 
   Он должен быть гибким и легко настраиваемым для использования в различных сценариях интерфейса.
2. Общие требования:
  * Компонент должен поддерживать SSR.
  * Использование Composition API + `<script setup>`.
  * Prop типизация через `defineProps<T>()`.
  * Slots типизация через `defineSlots<T>()`.
  * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
  * Реактивный функционал должен быть реализован в composable `useButton`.
  * Компонент должен поддерживать различные HTML теги для рендеринга (например, `button`, `a`, `span`).
  * Должна быть возможность задавать тип кнопки (например, `button`, `submit`, `reset`).
  * Компонент должен поддерживать различные размеры (`small`, `medium`, `large`).
  * Должна быть возможность задавать позицию иконки относительно текста (`left`, `right`, `top`, `bottom`).
  * Компонент должен поддерживать различные состояния (например, `disabled`, `loading`, `selected`).
  * Должна быть возможность задавать дополнительные CSS классы для кастомизации внешнего вида.
4. Пропсы:
  * `tag` (тип: `TButtonPropsTag`, по умолчанию: `'button'`): HTML тег для рендеринга компонента.
  * `type` (тип: `TButtonPropsType`, по умолчанию: `'button'`): Тип кнопки (актуально только для тега `button`).
  * `iconPosition` (тип: `TButtonPropsIconPosition`, по умолчанию: `'left'`): Позиция иконки относительно текста.
  * `size` (тип: `TButtonPropsSize`, по умолчанию: `'medium'`): Размер кнопки.
  * `rounded` (тип: `boolean`, по умолчанию: `false`): Закругленные углы кнопки.
  * `textual` (тип: `boolean`, по умолчанию: `false`): Текстовый стиль кнопки.
  * `outlined` (тип: `boolean`, по умолчанию: `false`): Контурный стиль кнопки.
  * `selected` (тип: `boolean`, по умолчанию: `false`): Состояние выбора кнопки.
  * `disabled` (тип: `boolean`, по умолчанию: `false`): Состояние отключения кнопки.
  * `loading` (тип: `boolean`, по умолчанию: `false`): Состояние загрузки кнопки.
  * `cssClass` (тип: `string`, по умолчанию: `'ar-button'`): CSS класс для корневого элемента.
  * `modifier` (тип: `TSharedPropsModifier`, по умолчанию: `undefined`): Модификатор базового CSS класса.
5. Слоты:
  * `default`: Слот для основного содержимого кнопки (текст).
  * `icon`: Слот для иконки кнопки.
  * `loading`: Слот для содержимого, отображаемого в состоянии загрузки.
6. События:
  * `click`: Событие, возникающее при клике на кнопку. Передает объект события `MouseEvent`.
7. Требования к стилям:
  * Отсутствуют.

9. Требования к документации:

  * Добавить TSDoc-комментарии к типам, компоненту и composable.
