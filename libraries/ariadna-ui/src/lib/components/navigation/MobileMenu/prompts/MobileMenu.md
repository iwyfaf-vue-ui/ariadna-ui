## Компонент MobileMenu.vue
Техническое задание для компонента MobileMenu:

1. Назначение
    * Компонент `MobileMenu` предназначен для отображения навигационного меню в мобильной версии веб-приложения. Он 
   обеспечивает удобный доступ к основным разделам сайта или приложения, поддерживает вложенные меню и плавные анимации
   открытия/закрытия.
2. Общие требования:
    * Компонент должен поддерживать SSR.
    * Использование Composition API + `<script setup>`.
    * Prop типизация через `defineProps<T>()`.
    * Slots типизация через `defineSlots<T>()`.
    * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
    * Реактивное управление состоянием меню реализовано в composable `useMobileMenu`.
    * Управление стеком открытых подменю реализовано в composable `useMobileMenuStack`.
    * Отображение списка пунктов меню с поддержкой вложенных подменю.
    * Управление состоянием открытого пункта меню.
    * Эмит событий при открытии и закрытии меню.
    * Поддержка кастомных шаблонов для элементов меню через слоты.
4. Пропсы:
    * `menu` (`Array<TMobileMenuItem>`, обязательный) — массив пунктов меню для отображения.
    * `animationTime` (`number`, необязательный) — время анимации открытия/закрытия меню в миллисекундах.
    * `cssClass` (`string`, по умолчанию '`EMobileMenuPropsDefault.CSS_CLASS`') — базовый CSS класс.
    * `ariaLabel` (`string`, необязательный) — атрибут `aria-label` для навигационного элемента `<nav>`.
5. Слоты:
   * `navbarItem` — слот кастомного шаблона для элемента навигационной панели.
      * `item` — данные элемента меню в navbar.
      * `opened` — открыт ли в данный момент пункт navbar панели меню.
   * `allContent` — слот для кастомного рендеринга всего содержимого меню.
      * `currentMenuItem` — текущий активный пункт меню.
      * `menu` — массив всех пунктов меню.
      * `opened` — булево значение, открыто ли меню.
      * `onClick` — функция обратного вызова при клике на пункт меню.
   * `pageStackTitle` — слот для рендеринга заголовка в стеке страниц.
      * `item` — пункт меню для заголовка. 
      * `level` — уровень вложенности в стеке страниц. 
      * `opened` — булево значение, открыто ли меню.
   * `itemBeforeIcon` — слот для рендеринга заголовка в стеке страниц.
      * `icon` — имя иконки.
      * `opened` — булево значение, открыт ли пункт меню.
   * `itemAfterIcon` — слот для рендеринга иконки после текста пункта меню.
      * `icon` — имя иконки.
      * `opened` — булево значение, открыт ли пункт меню.
   * `itemLabel` — слот для рендеринга текста пункта меню.
      * `label` — текст метки пункта меню.
      * `opened` — булево значение, открыт ли пункт меню.
   * `item` — слот для рендеринга произвольного пункта меню.
      * `item` — данные пункта меню.
      * `opened` — булево значение, открыт ли пункт меню.
   * `backIcon` — слот для рендеринга иконки кнопки "назад".
      * `back` — обработчик события возврата.
      * `opened` — булево значение, открыт ли пункт меню.
   * `closeIcon` — слот для рендеринга иконки кнопки "закрыть".
      * `close` — обработчик события закрытия.
      * `opened` — булево значение, открыт ли пункт меню.
   * `headerLabel` — слот для рендеринга заголовка в шапке меню.
      * `opened` — булево значение, открыто ли меню.
      * `item` — текущий пункт меню или null.
   * `fullHeader` — слот для рендеринга полной шапки меню, включая заголовок и иконки.
      * `opened` — булево значение, открыто ли меню.
      * `label` — текст заголовка.
      * `back` — обработчик события возврата.
      * `close` — обработчик события закрытия.
      * `backVisible` — булево значение, видна ли кнопка "назад".
   * `loading` — слот для рендеринга состояния загрузки.
      * `opened` — булево значение, открыто ли меню.
      * `item` — текущий пункт меню.
  * `[key: string]` — дополнительные кастомные слоты для конкретных пунктов меню (например, `page-${menu.key}`).
     * `item` — данные пункта меню.
     * `opened` — булево значение, открыт ли пункт меню.
     * `onClick` — функция обратного вызова при клике на пункт меню.
6. События:
   * `open` — срабатывает при открытии меню.
   * `close` — срабатывает при закрытии меню.
