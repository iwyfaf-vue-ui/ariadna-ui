# Техническое задание

Необходимо полностью реализовать Vue 3 компонент DesktopMenu.vue по требованиям ниже, включая ВСЕ перечисленные в
структуре файлы.

## Структура:

```text
├── DesktopMenu                                            # Каталог с именем компонента
│   ├── composables                                        # Каталог с описанием реактивной функциональности компонента (Vue 3)
│   │   ├── useDesktopMenu                                 # Каталог с composable useDesktopMenu
│   │   │   ├── useDesktopMenu.ts                          # Composable useDesktopMenu
│   │   │   ├── useDesktopMenu.types.ts                    # Типы composable useDesktopMenu
│   ├── tests                                              # Каталог с Unit-тестами компонента
│   │   ├── components                                     # Каталог с Unit-тестами для компонентов
│   │   │   ├── DesktopMenu.test.ts                        # Unit-тесты главного компонента
│   │   ├── composables                                    # Каталог с Unit-тестами для composables
│   │   │   ├── useDesktopMenu.test.ts                     # Unit-тесты composable useDesktopMenu
│   ├── types                                              # Каталог с типами компонента
│   │   ├── DesktopMenu.enums.ts                           # Enums компонента со значениями props по умолчанию
│   │   ├── DesktopMenu.types.ts                           # Types компонента

```

## Компонент DesktopMenu.vue
Техническое задание для компонента DesktopMenu:

1. Назначение
    * Компонент DesktopMenu — предназначен для отображения многоуровневого меню на десктопных устройствах. Он 
   обеспечивает удобную навигацию с поддержкой раскрывающихся подменю, управляемых кликом или наведением, и позволяет
   кастомизировать отображение элементов меню.
2. Общие требования:
    * Компонент должен поддерживать SSR.
    * Использование Composition API + `<script setup>`.
    * Prop типизация через `defineProps<T>()`.
    * Slots типизация через `defineSlots<T>()`.
    * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
    * Реактивный функционал должен быть реализован в composable `useDesktopMenu`.
    * Отображение меню с несколькими уровнями вложенности (минимум 3 уровня).
    * Управление видимостью подменю через клик или наведение (определяется пропсом `expandMode`).
    * Поддержка ограничения видимых элементов третьего уровня через проп `visibleItems` с возможностью раскрытия 
   полного списка.
    * Отображение оверлея при активном меню с возможностью закрытия меню по клику на оверлей.
    * Обработка состояния ошибки и загрузки с отображением соответствующих слотов.
4. Пропсы:
    * `data: TSharedMenu[]` — массив данных меню (обязательный).
    * `expandMode?: 'click' | 'hover'` — режим раскрытия подменю (по умолчанию 'click').
    * `visibleItems?: number` — количество видимых элементов третьего уровня (по умолчанию 0 — без ограничения).
    * `overlay?: boolean` — отображать ли оверлей (по умолчанию true).
    * `invalid?: boolean` — состояние ошибки компонента (по умолчанию false).
    * `cssClass?: string` — базовый CSS-класс компонента (по умолчанию 'desktop-menu').
5. Слоты:
    * `rubricator` — слот для кастомного рендера первого уровня меню, получает данные и методы управления видимостью 
   второго уровня.
    * `menu` — слот для рендера элементов меню с расширенными контролами, получает данные, состояние "показать больше" 
   и методы управления.
    * `loading` — слот для отображения состояния загрузки.
    * `error` — слот для отображения состояния ошибки.
6. События:
   * `mounted` — эмитируется при монтировании компонента.
   * `click:overlay` — эмитируется при клике на оверлей.
