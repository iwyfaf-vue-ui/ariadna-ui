# Техническое задание

Необходимо полностью реализовать Vue 3 компонент Dropbox.vue по требованиям ниже, включая ВСЕ перечисленные в
структуре файлы.

## Структура:

```text
├── Dropbox                                           # Каталог с именем компонента
│   ├── composables                                   # Каталог с описанием реактивной функциональности компонента (Vue 3)
│   │   ├── useDropbox                                # Каталог с composable useDropbox
│   │   │   ├── useDropbox.ts                         # Composable useDropbox
│   │   │   ├── useDropbox.types.ts                   # Типы composable useDropbox
│   ├── tests                                         # Каталог с Unit-тестами компонента
│   │   ├── components                                # Каталог с Unit-тестами для компонентов
│   │   │   ├── Dropbox.test.ts                       # Unit-тесты главного компонента
│   │   ├── composables                               # Каталог с Unit-тестами для composables
│   │   │   ├── useDropbox.test.ts                    # Unit-тесты composable useDropbox
│   ├── types                                         # Каталог с типами компонента
│   │   ├── Dropbox.enums.ts                          # Enums компонента со значениями props по умолчанию
│   ├── Dropbox.vue                                   # Основной (входной) файл элемента
│   ├── Dropbox.d.ts                                  # Основной файл с типами элементов
```

## Компонент Dropbox.vue
Техническое задание для компонента Dropbox:

1. Назначение
    * Компонент Dropbox предназначен для отображения выпадающего контейнера с пользовательским содержимым, который 
   открывается по действию пользователя (например, по клику на активатор). Компонент обеспечивает управление видимостью
   содержимого, обработку событий закрытия по клику вне компонента или по нажатию клавиши Escape, а также поддержку
   пользовательских слотов для гибкой кастомизации.
2. Общие требования:
    * Компонент должен поддерживать SSR.
    * Использование Composition API + `<script setup>`.
    * Prop типизация через `defineProps<T>()`.
    * Slots типизация через `defineSlots<T>()`.
    * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
    * Реактивный функционал должен быть реализован в composable `useDropbox`.
    * Управление открытием/закрытием через `v-model`.
    * Поддержка закрытия по клику вне компонента.
    * Поддержка закрытия по нажатию Escape.
    * Возможность отключения автоматического позиционирования.
    * Поддержка модификаторов для кастомизации классов.
    * Предоставление методов управления состоянием (`open`, `close`, `toggle`, `calculate`) через `expose`.
    * Поддержка пользовательских слотов: `activator`, `header`, `default`.
4. Пропсы:
    * `modelValue: boolean` — состояние открытия компонента (обязательный, v-model).
    * `disableAutoPosition?: boolean` — отключение автоматического позиционирования (по умолчанию: false).
    * `closeOnClickOutside?: boolean` — закрытие при клике вне компонента (по умолчанию: false).
    * `closeOnEscape?: boolean` — закрытие по нажатию Escape (по умолчанию: true).
    * `cssClass?: EDropboxPropsDefault.CSS_CLASS` — базовый CSS-класс для корневого элемента и потомков 
   (по умолчанию: 'ar-dropbox').
    * `modifier?: string` — модификатор для базового CSS-класса (опционально).
5. Слоты:
    * `activator` — слот для элемента-активатора (например, кнопка), получает пропсы: `{ opened, open, close, toggle }`.
    * `header` — слот для заголовка выпадающего контейнера, получает пропсы: `{ opened, open, close, toggle }`.
    * `default` — основной слот для пользовательского содержимого, получает пропсы: `{ opened }`.
6. События:
   * `update:model-value` — эмитится при изменении состояния открытия, передаёт новое значение `modelValue`.
   * `show` — эмитится при открытии компонента.
   * `hide` — эмитится при закрытии компонента.
