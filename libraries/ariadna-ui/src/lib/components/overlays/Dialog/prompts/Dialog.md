# Техническое задание

Необходимо полностью реализовать Vue 3 компонент Dialog.vue по требованиям ниже, включая ВСЕ перечисленные в
структуре файлы.

## Структура:

```text
├── Dialog                                            # Каталог с именем компонента
│   ├── composables                                   # Каталог с описанием реактивной функциональности компонента (Vue 3)
│   │   ├── useDialog                                 # Каталог с composable useDialog
│   │   │   ├── useDialog.ts                          # Composable useDialog
│   │   │   ├── useDialog.types.ts                    # Типы composable useDialog
│   ├── tests                                         # Каталог с Unit-тестами компонента
│   │   ├── components                                # Каталог с Unit-тестами для компонентов
│   │   │   ├── Dialog.test.ts                        # Unit-тесты главного компонента
│   │   ├── composables                               # Каталог с Unit-тестами для composables
│   │   │   ├── useDialog.test.ts                     # Unit-тесты composable useDialog
│   ├── types                                         # Каталог с типами компонента
│   │   ├── Dialog.enums.ts                           # Enums компонента со значениями props по умолчанию
│   ├── Dialog.vue                                    # Основной (входной) файл элемента
│   ├── Dialog.d.ts                                   # Основной файл с типами элементов
```

## Компонент Dialog.vue
Техническое задание для компонента Dialog:

1. Назначение
    * Компонент Dialog предназначен для отображения модального окна (диалога) с возможностью кастомизации содержимого
   через слоты, управления видимостью, размерами, поведением при взаимодействии пользователя (перетаскивание, 
   максимизация, закрытие) и поддержкой различных режимов отображения.
2. Общие требования:
    * Компонент должен поддерживать SSR.
    * Использование Composition API + `<script setup>`.
    * Prop типизация через `defineProps<T>()`.
    * Slots типизация через `defineSlots<T>()`.
    * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
    * Реактивный функционал должен быть реализован в composable `useDialog`.
    * Управление видимостью диалога через проп `visible`.
    * Поддержка максимизации окна.
    * Возможность перетаскивания диалога, неактивно при максимизации.
    * Опция прокрутки только содержимого диалога.
    * Режим "persistent" для предотвращения закрытия диалога при клике вне или нажатии ESC.
    * Эффект "тряски" диалога для привлечения внимания.
    * Отображение/скрытие оверлея.
    * Возможность указать целевой элемент для телепортации через appendTo.
    * Поддержка слотов для заголовка, содержимого и футера с передачей управляющих функций (например, скрыть диалог,
   переключить максимизацию).
4. Пропсы:
    * `visible` (`boolean`, обязательный) — видимость диалога.
    * `maximized` (`boolean`, по умолчанию `false`) — максимизация диалога.
    * `draggable` (`boolean`, по умолчанию `false`) — возможность перетаскивания.
    * `contentScrollable` (`boolean`, по умолчанию `false`) — прокрутка содержимого.
    * `persistent` (`boolean`, по умолчанию `false`) — запрет закрытия кликом вне и ESC.
    * `noOverlayDismiss` (`boolean`, по умолчанию `false`) — запрет закрытия кликом по оверлею.
    * `noEscDismiss` (`boolean`, по умолчанию `false`) — запрет закрытия по ESC.
    * `shake` (`boolean`, по умолчанию `false`) — эффект тряски.
    * `overlay` (`boolean`, по умолчанию `true`) — отображение оверлея.
    * `appendTo` (`string` | 'body', по умолчанию '`EDialogPropsDefault.APPEND_TO`') — селектор или элемент для телепортации.
    * `cssClass` (`string`, по умолчанию '`EDialogPropsDefault.CSS_CLASS`') — базовый CSS класс.
    * `modifier` (`string`, необязательный) — модификатор CSS класса.
5. Слоты:
    * `header` — слот для заголовка диалога, получает функции `hide` (скрыть диалог) и `toggleMaximize` (переключить 
   максимизацию)
    * `content` — слот для основного содержимого диалога.
    * `footer` — слот для футера диалога.
6. События:
   * `mounted` — при монтировании компонента.
   * `update:visible` — при изменении видимости.
   * `show` — при показе диалога.
   * `hide` — при скрытии диалога, передается событие.
   * `after-hide` — после завершения анимации скрытия.
   * `maximized` — при максимизации, передается событие.
   * `unMaximized` — при отмене максимизации, передается событие.
   * `drag-start` — начало перетаскивания.
   * `drag-end` — окончание перетаскивания.
7. Требования к стилям:
