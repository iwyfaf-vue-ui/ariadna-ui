Необходимо полностью реализовать Vue 3 компонент Previewer.vue по требованиям ниже, включая ВСЕ перечисленные в
структуре файлы.

```text
├── Previewer                                         # Каталог с именем компонента
│   ├── composables                                   # Каталог с описанием реактивной функциональности компонента (Vue 3)
│   │   ├── usePreviewer                              # Каталог с composable usePreviewer
│   │   │   ├── usePreviewer.ts                       # Composable usePreviewer
│   │   │   ├── usePreviewer.types.ts                 # Типы composable usePreviewer
│   ├── tests                                         # Каталог с Unit-тестами компонента
│   │   ├── components                                # Каталог с Unit-тестами для компонентов
│   │   │   ├── Previewer.test.ts                     # Unit-тесты главного компонента
│   │   ├── composables                               # Каталог с Unit-тестами для composables
│   │   │   ├── usePreviewer.test.ts                  # Unit-тесты composable usePreviewer

│   │   ├── Previewer.enums.ts                        # Enums компонента со значениями props по умолчанию

│   ├── Previewer.d.ts                                # Основной файл с типами элементов
```

## Компонент Previewer.vue
Техническое задание для компонента Previewer:

1. Назначение
   * Компонент для демонстрации других Vue-компонентов с возможностью отображения исходного кода компонента.
2. Общие требования:
   * Компонент должен поддерживать SSR.
   * Использование Composition API + `<script setup>`.
   * Prop типизация через `defineProps<T>()`.
   * Slots типизация через `defineSlots<T>()`.
   * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
   * Реактивный функционал должен быть реализован в composable `usePreviewer`.
   * Принимать любой Vue-компонент через prop `component` и отображать его.
   * Отображать HTML-код компонента с текущими пропсами.
   * Генерирует HTML-код компонента с текущими пропсами.
   * Кнопка "Показать/скрыть код" с возможностью кастомизации через слот.
   * Кнопка "Скопировать код" с возможностью кастомизации через слот.
   * Анимация раскрытия/скрытия блока кода.
4. Пропсы:
   * `component: Object/String` — Компонент для рендеринга (обязательный).
   * `showCode: Boolean` — 	Показывать блок с кодом (`false` по умолчанию).
   * `showCodeToggle: Boolean` — Показывать кнопку "Код" (`true` по умолчанию).
   * `cssClass: String` — CSS-класс корневого элемента (по умолчанию `'ar-previewer'`).
5. Слоты:
   * `header` — слот для заголовка.
   * `description` — слот для описания.
   * `showCodeToggle` — слот для кнопки "Показать/скрыть код".
   * `copy` — слот для кнопки "Скопировать код".
   * `source` — слот для блока с исходным кодом.
6. События:
   * Отсутствуют.
7. Требования к стилям:
   * Отсутствуют.

9. Требования к документации:

   * Добавить TSDoc-комментарии к типам, компоненту и composable.
   * Описание сценариев применения компонента.
