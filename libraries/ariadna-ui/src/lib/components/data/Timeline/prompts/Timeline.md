# Техническое задание

Необходимо полностью реализовать Vue 3 компонент Timeline.vue по требованиям ниже, включая ВСЕ перечисленные в
структуре файлы.

## Структура:

```text
├── Timeline                                            # Каталог с именем компонента
│   ├── composables                                     # Каталог с описанием реактивной функциональности компонента (Vue 3)
│   │   ├── useTimeline                                 # Каталог с composable useTimeline
│   │   │   ├── useTimeline.ts                          # Composable useTimeline
│   │   │   ├── useTimeline.types.ts                    # Типы composable useTimeline
│   ├── tests                                           # Каталог с Unit-тестами компонента
│   │   ├── components                                  # Каталог с Unit-тестами для компонентов
│   │   │   ├── Timeline.test.ts                        # Unit-тесты главного компонента
│   │   ├── composables                                 # Каталог с Unit-тестами для composables
│   │   │   ├── useTimeline.test.ts                     # Unit-тесты composable useTimeline
│   ├── types                                           # Каталог с типами компонента
│   │   ├── Timeline.enums.ts                           # Enums компонента со значениями props по умолчанию
│   │   ├── Timeline.types.ts                           # Types компонента
│   ├── Timeline.vue                                    # Основной (входной) файл элемента
│   ├── Timeline.d.ts                                   # Основной файл с типами элементов
```

## Компонент Timeline.vue
Техническое задание для компонента Timeline:

1. Назначение
    * Компонент Timeline предназначен для визуализации последовательности событий, расположенных по временной шкале. 
   Он отображает события с возможностью позиционирования слева или справа, поддерживает кастомизацию через слоты и 
   позволяет гибко управлять отображением каждого события.
2. Общие требования:
    * Компонент должен поддерживать SSR.
    * Использование Composition API + `<script setup>`.
    * Prop типизация через `defineProps<T>()`.
    * Slots типизация через `defineSlots<T>()`.
    * Emits типизация через `defineEmits<T>()`.
3. Функциональные требования
    * Реактивный функционал должен быть реализован в composable `useTimeline`.
    * Отображение списка событий с позиционированием каждого события слева или справа.
    * Поддержка кастомных CSS классов и модификаторов для стилизации.
    * Валидация наличия ключевого свойства в каждом событии, выброс ошибки при отсутствии.
    * Возможность отображения дополнительных элементов через слоты: содержимое события, противоположная сторона, 
   разделитель.
    * Корректная обработка пустого списка событий (отсутствие рендеринга событий).
    * Обеспечение корректного рендеринга первого и последнего события с соответствующими CSS классами.
4. Пропсы:
    * `events: Array<Data>` — массив событий для отображения, где Data расширяет базовый тип события. Обязательный.
    * `keyProperty?: string` — имя свойства в событии, используемое как ключ в цикле. По умолчанию 
   `ETimelinePropsDefault.KEY_PROPERTY`.
    * `cssClass?: string` — базовый CSS класс для компонента. По умолчанию `ETimelinePropsDefault.CSS_CLASS`.
    * `modifier?: TSharedPropsModifier` — дополнительный CSS модификатор для компонента.
5. Слоты:
    * `event` — слот для кастомного рендеринга содержимого события. Получает параметры: 
   `{ event: Data, index: number }`.
    * `separator` — слот для рендеринга разделителя между событиями. Получает параметры: 
   `{ event: Data, index: number }`.
    * `opposite` — слот для рендеринга содержимого с противоположной стороны события. Получает параметры: 
   `{ event: Data, index: number }`.
