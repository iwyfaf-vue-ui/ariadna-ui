# Компонент VirtualScroller.vue

Техническое задание для компонента VirtualScroller:

Необходимо полностью реализовать Vue 3 компонент VirtualScroller.vue по требованиям ниже, включая ВСЕ перечисленные в
структуре файлы.

## Структура:

```text
├── VirtualScroller                                        # Каталог с именем компонента
│   ├── composables                                        # Каталог с описанием реактивной функциональности компонента (Vue 3)
│   │   ├── useVirtualScroller                             # Каталог с composable useVirtualScroller
│   │   │   ├── useVirtualScroller.ts                      # Composable useVirtualScroller
│   │   │   ├── useVirtualScroller.types.ts                # Типы composable useVirtualScroller
│   ├── tests                                              # Каталог с Unit-тестами компонента
│   │   ├── components                                     # Каталог с Unit-тестами для компонентов
│   │   │   ├── VirtualScroller.test.ts                    # Unit-тесты главного компонента
│   │   ├── composables                                    # Каталог с Unit-тестами для composables
│   │   │   ├── useVirtualScroller.test.ts                 # Unit-тесты composable useVirtualScroller
│   ├── types                                              # Каталог с типами компонента
│   │   ├── VirtualScroller.enums.ts                       # Enums компонента
│   │   ├── VirtualScroller.types.ts                       # Типы компонента

│   ├── VirtualScroller.d.ts                               # Основной файл с типами элементов
```

## Описание компонента

Компонент VirtualScroller предназначен для отображения больших списков данных с использованием техники виртуализации. 
Вместо отрисовки всех элементов списка одновременно, компонент отображает только те элементы, которые видны в текущей
области просмотра, что значительно улучшает производительность при работе с большими объемами данных.

## Общие требования

- Компонент должен поддерживать SSR.
- Использование Composition API + `<script setup>`.
- Props типизация через `defineProps<T>()`.
- Slots типизация через `defineSlots<T>()`.
- Emits типизация через `defineEmits<T>()`.
- Строгое разделение логики, типов, core-функционала и тестов по соответствующим директориям.

## Функциональные требования

- Компонент должен динамически рассчитывать и отображать только видимые элементы списка.
- Компонент должен поддерживать прокрутку списка с плавной анимацией.
- Компонент должен предоставлять методы для программного управления прокруткой (например, прокрутка к определенному 
элементу).
- Компонент должен поддерживать настройку высоты элементов списка и высоты контейнера.
- Компонент должен поддерживать настройку количества дополнительных элементов, отображаемых за пределами видимой 
области (overScan).

### Props

| Prop          | Required | Type          | Default                                  | Description                                                                                                                                                  |
|---------------|----------|---------------|------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `items`       | ✓        | `Array<Data>` | `[]`                                     | Данные виртуального скроллера.                                                                                                                               |
| `itemHeight`  | ✓        | `number`      | `undefined`                              | Высота каждого элемента списка (очень важно указать точную высоту). Передается в HTML структуру как CSS переменная. Нужен для правильно рассчета скроллинга. |
| `height`      | -        | `number`      | `EVirtualScrollerPropsDefault.HEIGHT`    | Высота компонента.                                                                                                                                           |
| `overscan`    | -        | `number`      | `EVirtualScrollerPropsDefault.OVERSCAN`  | Количество дополнительных элементов для рендера.                                                                                                             |
| `cssClass`    | -        | `string`      | `EVirtualScrollerPropsDefault.CSS_CLASS` | Переопределяет структуру CSS классов.                                                                                                                        |

### Slots

| Slot               | Description                                                                                                        |
|--------------------|--------------------------------------------------------------------------------------------------------------------|
| `default`          | Используется для кастомизации отображения каждого элементов списка.                                                |

### Emits

Эмитов нет.

### Exposes

| Prop                  | Type                             | Description                                                                         |
|-----------------------|----------------------------------|-------------------------------------------------------------------------------------|
| `scrollTo`            | `(index: number) => void`        | Используется для скролла на элемент по его индексу.                                 |
| `getVisibleIndexes`   | `() => TVirtualScrollerIndexes`  | Используется для получения начального и конечного индекса видимых элементов списка. |

### Поддержка клавиатуры

Поддержки клавиатуры нет.
