## Composable useFocusBlur
Техническое задание для composable useFocusBlur:

1. Назначение
   * Composable `useFocusBlur` предназначен для управления состоянием фокуса элемента или компонента во Vue-приложениях.
   Он предоставляет реактивное свойство, отражающее текущий статус фокуса, а также методы для обработки событий 
   получения и потери фокуса. Это позволяет удобно реализовывать UI-логику, зависящую от состояния фокуса, например, 
   отображение подсказок, изменение стилей или запуск побочных эффектов.
2. Общие требования:
   * Composable должна поддерживать SSR.
   * Использование Composition API.
3. Функциональные требования
   * Composable должен возвращать объект с реактивным свойством `isFocused` (тип `Ref<boolean>`), отражающим состояние 
   фокуса.
   * Должны быть реализованы методы `onFocus` и `onBlur` для установки и сброса состояния фокуса соответственно.
   * Состояние `isFocused` должно корректно обновляться при вызове соответствующих методов.
   * Каждый экземпляр composable должен поддерживать независимое состояние.
