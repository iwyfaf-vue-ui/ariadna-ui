## Composable useDelayedValue
Техническое задание для composable useDelayedValue:

1. Назначение
   * Composable `useDelayedValue` предназначен для создания реактивного значения с задержкой его обновления. Он
   позволяет управлять состоянием, при котором изменение значения происходит с заданной задержкой, что полезно для 
   реализации debounce-подобного поведения в интерфейсах. Composable возвращает два реактивных значения: мгновенное 
   (`immediateValue`) и отложенное (`delayedValue`).
2. Общие требования:
   * Composable должна поддерживать SSR.
   * Использование Composition API.
3. Функциональные требования
   * При инициализации composable принимает:
     - `initValue`: начальное значение, которое может быть как реактивным `ref`, так и обычным значением.
     - `delay`: время задержки в миллисекундах (по умолчанию 300 мс).
   * Возвращает объект с двумя реактивными свойствами:
     - `immediateValue`: обновляется мгновенно при инициализации и после срабатывания задержки.
     - `delayedValue`: реактивное значение, установка которого запускает обновление `immediateValue` с задержкой.
   * При установке нового значения в `delayedValue`:
     - Если задержка больше `0`, обновление `immediateValue` происходит после указанной задержки.
     - Если задержка равна `0` или отрицательна, `immediateValue` обновляется мгновенно.
     - Если новое значение устанавливается до истечения предыдущей задержки, предыдущий таймер сбрасывается.
   * При уничтожении скоупа composable должен корректно очищать все активные таймеры.
   * Изменение `initValue` после инициализации не должно автоматически влиять на `immediateValue` и `delayedValue`.
   * Обработка некорректных значений параметра delay (например, нечисловых) должна приводить к использованию значения 
   по умолчанию.
