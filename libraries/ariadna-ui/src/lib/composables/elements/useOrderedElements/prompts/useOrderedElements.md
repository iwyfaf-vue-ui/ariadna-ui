
## Composable useOrderedElements
Техническое задание для composable useOrderedElements:

1. Назначение
   * Composable `useOrderedElements` предназначен для управления упорядоченной коллекцией элементов (например, 
   DOM-элементов или любых других объектов). Composable предоставляет реактивный массив элементов и функции для 
   добавления, обновления и очистки элементов по индексам, обеспечивая упорядоченный доступ и управление элементами.
2. Общие требования:
   * Composable должна поддерживать SSR.
   * Использование Composition API.
3. Функциональные требования
   * Предоставлять реактивный массив элементов с возможностью доступа по индексу.
   * Функция `fillElements(element, index)` должна добавлять или обновлять элемент по указанному индексу, расширяя 
   массив при необходимости.
   * Функция `clearElements()` должна очищать весь массив элементов.
   * При уничтожении области видимости composable (scope disposal) автоматически очищать массив элементов.
   * Поддержка generic-типа элементов для возможности работы с любыми типами, не только HTMLElement.
   * Обеспечить корректную реактивность и обновление данных при изменениях элементов.

   * Покрыть composable unit-тестами:
5. Требования к документации:
   * Типы должны находится в отдельном файле `useOrderedElements.d.ts`;
   * Добавить TSDoc-комментарии к типам composable.
   * Описание сценариев применения composable.
