Необходимо полностью реализовать Vue 3 composable usePosition по требованиям ниже, включая ВСЕ перечисленные
в структуре файлы.


## Composable usePosition
Техническое задание для composable usePosition:

1. Назначение
   * Composable предназначен для динамического вычисления и управления позицией всплывающих элементов интерфейса (таких
   как dropdown, tooltip, popover) относительно целевого элемента (например, кнопки) с учетом доступного пространства,
   пользовательских настроек и особенностей контейнера.
2. Общие требования:
   * Composable должна поддерживать SSR.
   * Использование Composition API.
3. Функциональные требования
   * Composable должен принимать ссылки (`Ref`) на якорный элемент и позиционируемый элемент, а также объект опций.
   * Должна быть реализована поддержка различных вариантов позиционирования (`TOP`, `RIGHT`, `BOTTOM`, `LEFT`) с 
   возможностью задания приоритета.
   * Должна быть реализована возможность задания индивидуальных отступов (indents) для каждой стороны позиционирования.
   * Composable должен корректно рассчитывать координаты (`top`, `left`) для позиционируемого элемента с учетом 
   размеров контейнера, якоря и самого элемента.
   * Должна быть реализована реакция на изменение размеров контейнера, окна и позиционируемых элементов (например, 
   через `ResizeObserver` и обработчики событий `scroll`/`resize`).
   * Должна быть предусмотрена возможность отключения вычислений через опцию `disabled`.
   * Composable должен возвращать реактивные значения координат, css-классы для текущей позиции и функцию ручного 
   пересчета позиции.
   * В случае невозможности позиционирования (например, если ссылки равны null) координаты должны сбрасываться в 
   значения по умолчанию (например, 0).
   * Все вычисления должны быть максимально производительными и не вызывать лишних рендеров.
