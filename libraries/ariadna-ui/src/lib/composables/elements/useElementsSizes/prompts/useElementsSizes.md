в структуре файлы.


## Composable useElementsSizes
Техническое задание для composable useElementsSizes:

1. Назначение
   * Composable `useElementsSizes` предназначен для реактивного отслеживания размеров (ширина, высота, scrollWidth, 
   scrollHeight) одного или нескольких HTML-элементов, предоставляя актуальные значения в реактивном виде и 
   (опционально) вызывая обработчик при изменении размеров.
2. Общие требования:
   * Composable должна поддерживать SSR.
   * Использование Composition API.
3. Функциональные требования
   * Composable принимает ссылку (`Ref` или `ComputedRef`) на массив HTML-элементов.
   * Composable возвращает реактивный массив объектов с размерами каждого элемента (`width`, `height`, `scrollWidth`, 
   `scrollHeight`).
   * При изменении размеров любого из отслеживаемых элементов массив размеров должен обновляться автоматически.
   * При изменении списка отслеживаемых элементов (добавление, удаление, замена) composable должен корректно 
   пересоздавать наблюдателей и обновлять размеры.
   * Опционально может быть передан обработчик (`callback`), который вызывается при каждом изменении размеров с 
   актуальным массивом размеров.
   * При размонтировании компонента должны корректно очищаться все наблюдатели и ресурсы.
   * Composable не должен вызывать обработчик, если размеры не изменились.
   * Composable должен быть устойчив к отсутствию элементов (`null`, пустой массив).
