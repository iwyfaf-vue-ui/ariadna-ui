# Техническое задание

Необходимо полностью реализовать Vue 3 composable useElementSize по требованиям ниже, включая ВСЕ перечисленные
в структуре файлы.

## Структура:

```text
├── useElementSize                                    # Каталог с именем composable
│   ├── tests                                         # Каталог с Unit-тестами
│   │   ├── composable                                # Каталог с Unit-тестами для composable
│   │   │   ├── useElementSize.test.ts                # Unit-тесты главной composable
│   ├── types                                         # Каталог с типами composable
│   │   ├── useElementSize.types.ts                   # Типы composable
│   ├── useElementSize.ts                             # Основной (входной) файл элемента
│   ├── useElementSize.d.ts                           # Основной файл с типами элемента
```

## Composable useElementSize
Техническое задание для composable useElementSize:

1. Назначение
   * Composable `useElementSize` предназначен для получения реактивных значений размеров DOM-элемента (`width`, 
   `scrollWidth`, `height`, `scrollHeight`) с использованием API `ResizeObserver`. Позволяет отслеживать изменения 
   размеров элемента и выполнять дополнительную логику через опциональный обработчик.
2. Общие требования:
   * Composable должна поддерживать SSR.
   * Использование Composition API.
3. Функциональные требования
   * Использовать `ResizeObserver` для отслеживания изменений размеров элемента.
   * Обеспечить корректное подключение и отключение наблюдателя при монтировании и размонтировании компонента.
   * Обеспечить реактивное обновление возвращаемых значений: `width`, `scrollWidth`, `height`, `scrollHeight`.
   * При инициализации composable должен сразу получить текущие размеры элемента и установить наблюдатель.
   * При изменении размеров элемента обновлять реактивные значения.
   * При изменении отслеживаемого элемента корректно переключать наблюдателя на новый элемент.
   * При размонтировании компонента отключать наблюдателя для предотвращения утечек памяти.
   * Вызывать переданный обработчик с актуальными размерами при каждом изменении.
4. Требования к тестированию:
   * Покрыть composable unit-тестами:
5. Требования к документации:
   * Типы должны находится в отдельном файле `useElementSize.d.ts`;
   * Добавить TSDoc-комментарии к типам composable.
   * Описание сценариев применения composable.
