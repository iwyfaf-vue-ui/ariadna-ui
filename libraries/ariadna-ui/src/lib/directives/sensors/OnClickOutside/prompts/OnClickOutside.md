# Техническое задание

Необходимо полностью реализовать Vue 3 директиву OnClickOutside по требованиям ниже, включая ВСЕ перечисленные в 
структуре файлы.

## Структура:

```text
├── OnClickOutside                                    # Каталог с именем директивы
│   ├── tests                                         # Каталог с Unit-тестами
│   │   ├── directives                                # Каталог с Unit-тестами для директивы
│   │   │   ├── OnClickOutside.test.ts                # Unit-тесты главной директивы
│   ├── types                                         # Каталог с типами директивы
│   │   ├── OnClickOutside.enum.ts                    # Enum директивы
│   │   ├── OnClickOutside.types.ts                   # Типы директивы
│   ├── OnClickOutside.ts                             # Основной (входной) файл элемента
│   ├── OnClickOutside.d.ts                           # Основной файл с типами элемента
```

## Директива OnClickOutside
Техническое задание для директивы OnClickOutside:

1. Назначение
   * Директива предназначена для отслеживания кликов пользователя вне указанного DOM-элемента и вызова заданной 
   callback-функции при таком событии. Это позволяет реализовать поведение закрытия всплывающих окон, выпадающих 
   списков и других элементов интерфейса при клике вне их области.
2. Общие требования:
   * Директива должна поддерживать SSR.
   * Использование Composition API.
   * Директива должна корректно работать как на устройствах с мышью, так и на сенсорных устройствах (touch).
   * Необходимо обеспечить корректное удаление обработчиков событий при удалении элемента из DOM.
3. Функциональные требования
   * При монтировании элемента с директивой должен устанавливаться обработчик события (`click` или `touchstart`), 
   который отслеживает клики вне элемента.
   * Если пользователь кликает вне элемента, должна вызываться callback-функция, переданная в директиву.
   * При обновлении значения директивы (например, если callback-функция изменилась), старый обработчик должен быть
   удалён, а новый установлен.
   * При удалении элемента из DOM обработчик события должен быть корректно удалён.
   * Директива должна поддерживать работу с несколькими экземплярами на странице без конфликтов.
   * Директива не должна вызывать callback, если клик был внутри элемента.

   * Покрыть директиву unit-тестами:
5. Требования к документации:
   * Типы должны находится в отдельном файле `OnClickOutside.d.ts`;
   * Добавить TSDoc-комментарии к типам, директиве и composable.
   * Описание сценариев применения директивы.
