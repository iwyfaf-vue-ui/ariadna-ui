# Техническое задание

Необходимо полностью реализовать Vue 3 директиву RenderAttributeOnce.vue по требованиям ниже, включая ВСЕ перечисленные
в структуре файлы.

```text

│   ├── RenderAttributeOnce.ts                        # Основной (входной) файл элемента
│   ├── RenderAttributeOnce.d.ts                      # Основной файл с типами элемента
```

## Директива RenderAttributeOnce.vue
Техническое задание для директивы RenderAttributeOnce:

1. Назначение
   * Директива предназначена для однократного добавления заданных HTML-атрибутов к элементу при его создании, если эти
   атрибуты ещё не установлены. Используется для предотвращения повторной установки атрибутов при повторных рендерах
   компонента.
2. Общие требования:
   * Директива должна поддерживать SSR.
   * Использование Composition API.
   * Директива должна быть реализована как объект с хуками жизненного цикла Vue (например, `created`).
   * Директива должна быть совместима с SSR (Server-Side Rendering).
3. Функциональные требования
   * Директива должна принимать объект с парами ключ-значение, где ключ — имя атрибута, значение — его значение.
   * При инициализации элемента (хук created) директива должна пройтись по всем ключам объекта binding.value.
   * Для каждого ключа необходимо проверить, установлен ли уже соответствующий атрибут на элементе.
   * Если атрибут отсутствует, он должен быть установлен с указанным значением.
   * При SSR директива должна возвращать объект атрибутов для корректного рендера на сервере.

   * Описание сценариев применения директивы.
