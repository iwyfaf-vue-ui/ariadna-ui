## Директива TextareaAutoHeight
Техническое задание для директивы TextareaAutoHeight:

1. Назначение
   * Директива предназначена для автоматической подгонки высоты элемента `<textarea>` в зависимости от его содержимого.
   Это обеспечивает удобство ввода текста пользователем, предотвращая появление внутренних полос прокрутки и делая
   интерфейс более адаптивным.
2. Общие требования:
   * Директива должна поддерживать SSR.
   * Использование Composition API.
3. Функциональные требования
   * Необходимо обеспечить корректное удаление обработчиков событий при удалении элемента из DOM.
   * Директива должна корректно работать как при непосредственном применении к `<textarea>`, так и при применении к
     обёртке, содержащей `<textarea>`.
   * Необходимо предусмотреть обработку ошибок, если элемент `<textarea>` не найден.
   * Высота `<textarea>` должна обновляться при изменении его содержимого, а также при изменении размера окна браузера.
   * Директива должна предотвращать появление вертикальной полосы прокрутки у `<textarea>`.
4. BindingValues:
   * `timeout` (тип: `number`, по умолчанию: `400`): Тайм-аут (троттлинг) в миллисекундах для обработчика 
   автоматического изменения размера текстовой области.
5. Требования к тестированию:
   * Покрыть директиву unit-тестами:
6. Требования к документации:
   * Типы должны находится в отдельном файле `TextareaAutoHeight.d.ts`;
   * Добавить TSDoc-комментарии к типам, директиве и composable.
   * Описание сценариев применения директивы.
