## Директива PhoneMask
Техническое задание для директивы PhoneMask:

1. Назначение
   * Директива предназначена для реализации маски российских номеров телефонов в поле ввода (`input`). Она должна 
   обеспечивать корректное отображение номера телефона, включая разделители и маску, а также обрабатывать специальные 
   случаи, такие как удаление символов.
2. Общие требования:
   * Директива должна поддерживать SSR.
   * Использование Composition API.
   * Директива должна быть реализована как объект с хуками жизненного цикла Vue (например, `created`).
3. Функциональные требования
   * Директива должна поддерживать настройку маски, разделителя и возможности клонирования значения в другое поле.
   * Код должен быть модульным, с четким разделением на логические компоненты (например, форматирование, обработка 
   событий и т.д.).
   * Директива должна автоматически форматировать введенный номер телефона в соответствии с заданной маской 
   (например, `+7 (___) ___-__-__`).
   * Настройка маски и разделителя: Директива должна поддерживать настройку маски и разделителя через параметры.
   * Директива должна поддерживать возможность клонирования отформатированного значения в другое поле ввода.
   * Директива должна корректно обрабатывать события ввода (`input`) и удаления символов (`keydown`), включая обработку
   нажатия клавиши `backspace`.
   * Директива должна проверять наличие поля ввода и выбрасывать ошибку, если `input` поле не найдено.
4. BindingValues:
   * `clone` (тип: `boolean`, по умолчанию: `false`): Необязательный флаг, определяющий, следует ли клонировать `input`
   элемент для применение маски.
   * `separator` (тип: `string`, по умолчанию: `'-'`): Символ-разделитель для форматирования телефонного номера.
   Помогает логике маски применять правильный символ-раздитель.
