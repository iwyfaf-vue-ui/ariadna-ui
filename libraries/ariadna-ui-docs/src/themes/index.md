# Темы

По умолчанию UI компоненты поставляются без стилизации, вы можете стилизовать компоненты самостоятельно, либо 
воспользоваться одной из предложенных тем, для кастомизации внешнего вида компонентов.

## Использование

Все темы используют утилиту [ThemeBuilder](/utilities/facades/theme-builder/) и поставляются с двумя файлами:

**Файл визуализации темы**
```scss
@use '@iwyfaf-vue-ui/ariadna-ui/theme/ThemeName' as theme;
```

**Файл визуализации компонентов**
```scss
@use '@iwyfaf-vue-ui/ariadna-ui/components/ThemeName';
```

### Файл визуализации темы

В файле визуализации темы вы можете найти:

* Настроек брейкпоинтов;
* Настройки сетки (c debug режимом);
* Настройки контейнеров;
* Миксин с набором цветовых палитр;
* Миксины с настройками шрифтов;
* Миксины с отступами;
* Миксины с радиусами;
* Вспомогательные миксины `text-style-helper` и `column-offset`.
* И другие...

Файл темы визуализации темы вы можете найти по пути:

```text
/node_modules/@iwyfaf-vue-ui/ariadna-ui/dist/styles/themes/ThemeName/ThemeName.scss
```

Рядом же будет лежать файл с авто-документацией темы:

```text
/node_modules/@iwyfaf-vue-ui/ariadna-ui/dist/styles/themes/ThemeName/ThemeName.md
```

Он поможет вам разобраться с перечнем доступных миксинов и CSS переменных темы, которые вы сможете использовать в
своих проектах.

### Файл визуализации компонентов

В файле визуализации компонентов собрана стилизация самих UI компонентов библиотеки. Эти файлы используют файл 
визуализации темы, но для гибкости, вы можете импортировать лишь файл визуализации темы и застилизовать UI компоненты
самостоятельно.
