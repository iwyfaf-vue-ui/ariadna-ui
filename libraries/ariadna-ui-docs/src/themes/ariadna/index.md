# Тема Ariadna

Тема вдохновлена визуальным видом приложения Asana и поставляется только в темных тонах. 

## Использование

**Файл визуализации темы**
```scss
@use '@iwyfaf-vue-ui/ariadna-ui/theme/Ariadna' as theme;
```

**Файл визуализации компонентов**
```scss
@use '@iwyfaf-vue-ui/ariadna-ui/components/Ariadna';
```
