# Clamp

Clamp - это функция, которая ограничивает заданное значение указанными минимальными и максимальными пределами.

Вес <Badge type="info">~ 0.13 kB gzipped.</Badge>

## Описание

- Если значение меньше минимального, возвращается минимальное значение.
- Если значение больше максимального, возвращается максимальное значение.
- В противном случае возвращается само значение.

### Аргументы

| Argument | Required | Type      | Default | Description                                                                              |
|----------|----------|-----------|---------|------------------------------------------------------------------------------------------|
| min      | ✓        | `string`  | -       | Нижняя граница, к которой нужно привязать значение.                                      |
| middle   | ✓        | `string`  | -       | Значение, которое должно быть зафиксировано между минимальным и максимальным значениями. |
| max      | ✓        | `string`  | -       | Верхняя граница, к которой должно быть привязано значение.                               |
