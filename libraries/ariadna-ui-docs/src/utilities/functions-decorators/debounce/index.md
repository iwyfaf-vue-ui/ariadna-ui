# Debounce

Debounce - это функция-декоратор, которая позволяет откладывать выполнение  функции до тех пор, пока не пройдет 
определенное время без новых вызовов этой функции.

Вес <Badge type="info">~ 0.41 kB gzipped.</Badge>

## Описание

Функция-декоратор `debounce` создает debounced версию предоставленной `callback` функции. Debounced функция задерживает
вызов `callback` функции до тех пор, пока не истечет заданный тайм-аут с момента ее последнего вызова. При желании,
`callback` функция может быть вызвана немедленно без ожидания тайм-аута, если `immediate` параметр установлен в `true`.

## Применение функции

Для использования функции debounce в вашем проекте, импортируйте её в нужном компоненте или модуле и оберните функцию,
которую хотите дебаунсить.

```typescript
import debounce from '@iwyfaf-vue-ui/ariadna-ui/Debounce';
```

### Аргументы

| Argument     | Required | Type       | Default  | Description                                    |
|--------------|----------|------------|----------|------------------------------------------------|
| `callback`   | ✓        | `Function` | -        | Функция, которую нужно дебаунсить.             |
| `timeout`    | -        | `number`   | `300`    | Количество миллисекунд для задержки.           |
| `immediate`  | -        | `boolean`  | `false`  | Указывает, вызывать ли `callback` немедленно.  |
