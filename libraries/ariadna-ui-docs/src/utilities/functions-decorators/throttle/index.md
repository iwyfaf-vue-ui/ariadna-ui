# Throttle

Throttle - это функция-декоратор, которая ограничивает количество вызовов `callback` функции в единицу времени.

Вес <Badge type="info">~ 0.35 kB gzipped.</Badge>

## Описание

Функция-декоратор `throttle` предназначена для ограничения частоты вызова функции. Это полезно в случаях, когда 
необходимо предотвратить слишком частые вызовы функции, например, при обработке событий прокрутки, изменения размера
окна или ввода данных от пользователя. Утилита гарантирует, что функция будет вызываться не чаще, чем указанный 
интервал времени.

## Применение функции

Для использования функции `throttle` в вашем проекте, импортируйте её и оберните им нужную функцию.

```typescript
import throttle from '@iwyfaf-vue-ui/ariadna-ui/Throttle';
```

### Аргументы

| Argument   | Required | Type       | Default | Description                                                                        |
|------------|----------|------------|---------|------------------------------------------------------------------------------------|
| `callback` | ✓        | `Function` | -       | Функция, которую нужно троттлить.                                                  |
| `timeout`  | -        | `number`   | `300`   | Интервал времени (в миллисекундах), в течение которого функция должна троттлиться. |
