# Functions decorators

Набор "Функций-декораторов" (Helper Functions).

## Что такое функции-декораторы?

Декораторы функций (function decorators) в JavaScript — это функции, которые принимают другую функцию и возвращают 
новую функцию, расширяя или изменяя её поведение без изменения исходного кода.

Декораторы полезны для добавления дополнительной логики (например, логирования, кеширования, проверки прав) вокруг
основной функции.
