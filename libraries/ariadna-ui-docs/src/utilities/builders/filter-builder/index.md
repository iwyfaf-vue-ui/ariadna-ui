# FilterBuilder

`FilterBuilder` - это класс предоставляет Fluent API для создания сложных запросов фильтрации для массивов сущностей.
Он позволяет объединять логические операторы и средства выбора полей для построения расширенной логики фильтрации.

Вес <Badge type="info">~ 2.42 kB gzipped.</Badge>

## Описание

Утилита `FilterBuilder` предназначена для построения сложных фильтров над массивами объектов (сущностей) с помощью
цепочного Fluent API. Она позволяет динамически выбирать поля (в том числе вложенные), комбинировать их с помощью
логических операторов (`AND`/`OR`), а также применять пользовательские условия фильтрации к выбранным полям.
Утилита облегчает создание гибких и читаемых фильтров для обработки данных в приложениях.

## Применение класса

```typescript
import FilterBuilder from '@iwyfaf-vue-ui/ariadna-ui/FilterBuilder';
```

### Методы класса

| Argument          | Description                                                                                                      |
|-------------------|------------------------------------------------------------------------------------------------------------------|
| `select`          | Метод, отвечающий за выбор поля для фильтрации или создание цепочки вложенных полей.                             |
| `or`              | Метод, отвечающий за создание логической операции ИЛИ.                                                           |
| `and`             | Метод, отвечающий за создание логической операции И.                                                             |
| `configureFields` | Метод, отвечающий за быструю настройку полей и логических операций с ними. Аналог методов `select`, `or`, `and`. |
| `filter`          | Основной метод для фильтрации по условию обратного вызова.                                                       |

::: warning Цепочка полей
Обратите внимание на то, как строятся цепочки полей.

В примере ниже, логический оператор сработает отдельно для полей `mother` и `father`, но для полей
`children` и `name` отдельно оператор работать не будет. Он обработает цепочку и сработает для
обоих последнего поля - `name`, т.к. на этом поле заканчивается цепочка.

```typescript
filterBuilder
  .configureFields(
    [[{ field: 'mother' }], [{ field: 'father' }], [{ field: 'children' }, { field: 'name' }]],
    ELogicOperator.OR,
  )
  .filter<string>((item) => item.includes('Bill'));
```

Более наглядно это видно при использовании одиночных методов выборки:

```typescript
filterBuilder
  .select('mother')
  .or()
  .select('father')
  .or()
  .select('children')
  .select('name')
  .filter<string>((item) => item.includes('Bill'));
```

Правильно построенная выборка полей - залог успешной фильтрации.

:::
