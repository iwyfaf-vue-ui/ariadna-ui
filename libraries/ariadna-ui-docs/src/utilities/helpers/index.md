# Helpers

Набор "Вспомогательных функции" (Helper Functions).

## Что такое вспомогательные функции?

Вспомогательные функции (Helper Functions) — это небольшие, узкоспециализированные функции, предназначенные для 
выполнения часто повторяющихся задач, упрощения кода и соблюдения принципа DRY (Don't Repeat Yourself).

Вспомогательные функции (Helper Functions) можно определить по нескольких признакам:

1. **Узкая ответственность** – функция выполняет одну конкретную задачу;
2. **Переиспользование** – функцию можно использовать в разных частях кода, избегая дублирования логики;
3. **Чистая функция (Pure Function)** – не имеет побочных эффектов, возвращает новый результат на основе входа.
