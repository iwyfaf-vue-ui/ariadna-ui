# TextareaAutoHeight

`TextareaAutoHeight` - это Vue директива, предназначена для автоматической подгонки высоты элемента `<textarea>` в 
зависимости от его содержимого.

Вес <Badge type="info">~ 0.81 kB gzipped.</Badge>

## Описание

Vue-директива `TextareaAutoHeight` - реализует автоматическое регулирование высоты элемента `<textarea>` в зависимости
от его содержимого.

Этот функционал, обеспечивает удобство ввода текста пользователем, предотвращая появление внутренних полос прокрутки и
делая интерфейс более адаптивным.

## Применение директивы

Подключив директиву к проекту, на элемент, в котором есть элемент `<textarea>`, надо повесить директиву
`v-textarea-auto-height`:

::: warning Важно!
Директива автоматически проверяет наличие `<textarea>` элемента и если таковой не найден, выбрасывает исключение.
:::

## Параметры

Директива принимает следующий набор параметров:

| BindingValue | Required | Type     | Default | Description                                                                                                |
|--------------|----------|----------|---------|------------------------------------------------------------------------------------------------------------|
| `timeout`    | -        | `number` | `400`   | Тайм-аут (троттлинг) в миллисекундах для обработчика автоматического изменения размера текстовой области.  |
