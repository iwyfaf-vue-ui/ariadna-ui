# PhoneMask

`PhoneMask` - это Vue директива, предназначена для реализации маски российских номеров телефонов в поле ввода (`input`)
Она обеспечивает корректное отображение номера телефона, включая разделители и маску, а также обрабатывает специальные
случаи, такие как удаление символов.

Вес <Badge type="info">~ 1.64 kB gzipped.</Badge>

## Описание

Vue-директива `RenderAttributeOnce` - реализует маску для форматирования ввода номера телефона в поле `input` поле.

Она автоматически применяет маску к номеру телефона, используя переданный разделитель. Директива также поддерживает
опцию клонирования поля ввода, что позволяет улучшить UX от использования маски, например, при вводе телефона, с 
помощью клона `input` поля можно сохранять `placeholder`.

## Применение директивы

Подключив директиву к проекту, на `input` поле к которому необходимо применить маску, надо повесить директиву 
`v-phone-mask`:

::: warning Важно!
Директива `v-phone-mask` корректно работает только с двусторонней привязкой `v-model="inputTextNull"`. При передаче
значение через `value="inputTextNull"`, маска будет работать некорректно.
:::

## Параметры

Директива принимает следующий набор параметров:

| BindingValue | Required | Type      | Default | Description                                                                                                                 |
|--------------|----------|-----------|---------|-----------------------------------------------------------------------------------------------------------------------------|
| `clone`      | -        | `boolean` | `false` | Флажок, определяющий, следует ли клонировать `input` элемент для маскировки.                                                |
| `separator`  | -        | `string`  | `'-'`   | Символ-разделитель для форматирования телефонного номера. Помогает логике маски использовать правильный символ-разделитель. |
