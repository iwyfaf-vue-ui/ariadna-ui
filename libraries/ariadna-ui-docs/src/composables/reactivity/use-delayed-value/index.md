# useDelayedValue

`useDelayedValue` - это composable-функция, которая обеспечивает создание реактивного значения с задержкой его 
обновления.

Вес <Badge type="info">~ 0.32 kB gzipped.</Badge>

## Описание

`useDelayedValue` - composable-функция предназначенная для создания реактивного значения с задержкой его обновления. 
Она позволяет управлять состоянием, при котором изменение значения происходит с заданной задержкой, что полезно для
реализации debounce-подобного поведения в интерфейсах. Composable возвращает два реактивных значения: мгновенное
(`immediateValue`) и отложенное (`delayedValue`).

## Параметры composable

| Argument    | Required | Type              | Default | Description                                                                         |
|-------------|----------|-------------------|---------|-------------------------------------------------------------------------------------|
| `initValue` | ✓        | `MaybeRef<Value>` | -       | Начальное значение или реактивная ссылка на значение, которое должно быть отложено. |
| `delay`     | -        | `number`          | `300`   | Длительность задержки в миллисекундах перед обновлением значения.                   |

## Возвращаемые значение

| Property          | Type                                                                | Description                                                                                                  |
|-------------------|---------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------|
| `delayedValue`    | `Ref<UnwrapRef<Value>>`                                             | Реактивная ссылка, содержащая отложенную версию значения. Это значение обновляется после некоторой задержки. |
| `immediateValue`  | `Ref<UnwrapRef<Value>, Value \| UnwrapRef<Value>> \| Ref<any, any>` | Реактивная ссылка, содержащая текущую версию значения. Это значение обновляется мгновенно.                   |
