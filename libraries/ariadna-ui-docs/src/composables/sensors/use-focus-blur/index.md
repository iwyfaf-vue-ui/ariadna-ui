# useFocusBlur

`useFocusBlur` - это composable-функция предназначеная для предоставления реактивных утилит для отслеживания и 
обработки событий фокусировки и размытия внутри компонента или элемента.

Вес <Badge type="info">~ 0.20 kB gzipped.</Badge>

## Описание

`useFocusBlur` - composable-функция предназначенная для управления состоянием фокуса элемента или компонента во 
Vue-приложениях. Она предоставляет реактивное свойство, отражающее текущий статус фокуса, а также методы для обработки
событий получения и потери фокуса. Это позволяет удобно реализовывать UI-логику, зависящую от состояния фокуса, 
например, отображение подсказок, изменение стилей или запуск побочных эффектов.

## Возвращаемые значение

| Property    | Type                    | Description                                                                    |
|-------------|-------------------------|--------------------------------------------------------------------------------|
| `isFocused` | `Ref<boolean, boolean>` | Реактивная ссылка, указывающая, находится ли элемент в фокусе в данный момент. |
| `onFocus`   | `() => void`            | Функция обработчика, которая будет вызвана, когда элемент получит фокус.       |
| `onBlur`    | `() => void`            | Функция обработчика, которая вызывается, когда элемент теряет фокус.           |
