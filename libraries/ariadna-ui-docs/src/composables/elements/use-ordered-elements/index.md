# useOrderedElements

`useOrderedElements` - это composable-функция, которая предоставляет упорядоченный доступ к коллекции элементов. 
Она возвращает реактивные ссылки и утилиты для управления этими элементами и взаимодействия с ними в определенном 
порядке.

Вес <Badge type="info">~ 0.24 kB gzipped.</Badge>

## Описание

`useOrderedElements` - composable-функция предназначеная для управления упорядоченной коллекцией элементов (например,
DOM-элементов или любых других объектов). Composable предоставляет реактивный массив элементов и функции для
добавления, обновления и очистки элементов по индексам, обеспечивая упорядоченный доступ и управление элементами.

## Возвращаемые значение

| Property         | Type                                         | Description                                                                                    |
|------------------|----------------------------------------------|------------------------------------------------------------------------------------------------|
| `elements`       | `Ref<Array<Elements>>`                       | Реактивная ссылка на массив элементов.                                                         |
| `fillElements`   | `(element: Elements, index: number) => void` | Функция для добавления или обновления элемента с определенным индексом в упорядоченном списке. |
| `clearElements`  | `() => void`                                 | Функция для удаления всех элементов из коллекции.                                              |

## Применение функции
