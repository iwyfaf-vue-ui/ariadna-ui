# usePosition

`usePosition` - это composable-функция, которая обеспечивает логику реактивного позиционирования элементов контекста 
относительно целевого элемента кнопки.

Вес <Badge type="info">~ 1.36 kB gzipped.</Badge>

## Описание

`usePosition` - composable-функция предназначенная для динамического вычисления и управления позицией всплывающих 
элементов интерфейса (таких как dropdown, tooltip, popover) относительно целевого элемента (например, кнопки) с учетом
доступного пространства, пользовательских настроек и особенностей контейнера.

## Параметры composable

| Argument   | Required | Type                       | Default                      | Description                                                   |
|------------|----------|----------------------------|------------------------------|---------------------------------------------------------------|
| `button`   | ✓        | `Ref<HTMLElement \| null>` | -                            | Ссылка на элемент кнопки или активатора.                      |
| `dropbox`  | ✓        | `Ref<HTMLElement \| null>` | -                            | Ссылка на выпадающий или всплывающий элемент.                 |
| `options`  | -        | `TUsePositionOptions`      | `usePositionDefaultOptions`  | Объект конфигурации для настройки поведения позиционирования. |

## Опции options

| Property        | Required | Type                   | Default                                                                          | Description                                                                                                                   |
|-----------------|----------|------------------------|----------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------|
| `container`     | -        | `null \| HTMLElement`  | `null`                                                                           | Контейнер, относительно которого выполняются расчеты доступного пространства. По умолчанию используется видимая область окна. |
| `threshold`     | -        | `number`               | `0`                                                                              | Невидимый отступ для корректировки ширины/высоты окна при расчетах.                                                           |
| `disabled`      | -        | `() => boolean`        | `() => false`                                                                    | Отключает расчеты позиционирования, если значение `true`.                                                                     |
| `positionOrder` | -        | `Array<EUsePosition>`  | `[EUsePosition.BOTTOM, EUsePosition.TOP, EUsePosition.RIGHT, EUsePosition.LEFT]` | Управляет возможными вариантами позиционирования и их приоритетом.                                                            |
| `indents`       | -        | `TUsePositionIndents`  | По умолчанию устанавливаются специфические функции отступов для каждой позиции.  | Отступы для каждой стороны при позиционировании по оси X и Y.                                                                 |


## Возвращаемые значение

| Property             | Type           | Description                                                                                                                                                                                             |
|----------------------|----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `top`                | `Ref<number>`  | Вычисленное значение `top` позиции для выпадающего элемента относительно кнопки.                                                                                                                        |
| `left`               | `Ref<number>`  | Вычисленное значение `left` позиции для выпадающего элемента относительно кнопки.                                                                                                                       |
| `calculate`          | `() => void`   | Функция для ручного пересчета позиции выпадающего элемента.                                                                                                                                             |
| `cssClass`           | `Ref<string>`  | Используется вместо вычисляемых свойств `top` и `left` при необходимости если нужно позиционировать с помощью CSS. Возможные значения: `top`, `right`, `left`, `bottom`.                                |
| `secondaryCssClass`  | `Ref<string>`  | Используется для более подробного позиционирования и укажет на наличие свободного места перпендикулярно относительно значения cssClass. Возможные значения: `top`, `right`, `left`, `bottom`, `center`. |

## Применение функции 

Для использования composable-функции `usePosition` в вашем проекте, импортируйте её и вызовите, с нужной вам 
конфигурацией.

```typescript
import usePosition from '@iwyfaf-vue-ui/ariadna-ui/usePosition';
```

::: warning Важно!
Контейнер в котором вызывается контекстный элемент, должен быть `position: relative`, т.к. контекстный элемент
позиционируется абсолютно.
:::

::: warning Важно!
Кнопка-активатор должна находится внутри этого контейнера и должна быть доступным HTML-элементом. Если
кнопка-активатор является Vue-компонентом, возможно потребуется обернуть её в HTML-тег (как в примерах ниже).
:::

### Обычное применение

Использование без переопределения опций. Composable `usePosition` отрабтает при монтировании элемента.

::: danger Очень важно!
При монтировании спользуйте осторожно, может негативно повлиять CLS, т.к. калькуляция происходит при монтировании
компонента.
:::
