# useDragViewport

`useDragViewport` - это composable-функция, которая предоставляет функциональность перетаскивания для указанного 
целевого элемента в рамках `viewport`. Эта composable-функция позволяет отслеживать и обрабатывать события 
перетаскивания, поддерживая как HTML, так и SVG элементы.

Вес <Badge type="info">~ 0.90 kB gzipped.</Badge>

## Описание

`useDragViewport` - composable-функция предназначенная для предоставления функциональности `drag-and-drop` 
(перетаскивания) для целевого элемента внутри `viewport`. Она позволяет отслеживать координаты, состояние 
перетаскивания и управлять стилями перемещаемого элемента, поддерживая как HTML, так и SVG-элементы.

## Параметры composable

| Argument    | Required | Type                                      | Default                      | Description                                                                         |
|-------------|----------|-------------------------------------------|------------------------------|-------------------------------------------------------------------------------------|
| `container` | ✓        | `Ref<HTMLElement \| SVGElement \| null>`  | -                            | Элемент контейнера, который будет перетаскиваться.                                  |
| `target`    | ✓        | `Ref<HTMLElement \| SVGElement \| null>`  | -                            | Элемент внутри контейнера, которым будет реализовываться перетаскивание контейнера. |
| `options`   | -        | `TUseDragViewportOptions`                 | `usePositionDefaultOptions`  | Дополнительная конфигурация для настройки поведения перетаскивания.                 |

## Опции options

| Property          | Required | Type                       | Default                                                                          | Description                                                                                                                  |
|-------------------|----------|----------------------------|----------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------|
| `state`           | -        | `Ref<boolean>`             | `null`                                                                           | Статус видимости целевого элемента контейнера. Это необходимо для корректного удаления событий, когда целевой элемент скрыт. |
| `disabled`        | -        | `Ref<boolean>`             | `0`                                                                              | Отключает или включает перетаскивание.                                                                                       |
| `initialPosition` | -        | `{ x: number; y: number }` | `() => false`                                                                    | Начальное положение перетаскиваемого элемента.                                                                               |
| `onDragStart`     | -        | `() => void`               | `[EUsePosition.BOTTOM, EUsePosition.TOP, EUsePosition.RIGHT, EUsePosition.LEFT]` | Callback-функция, вызывается при запуске операции перетаскивания.                                                            |
| `onDragEnd`       | -        | `() => void`               | По умолчанию устанавливаются специфические функции отступов для каждой позиции.  | Callback-функция, вызывается по завершении операции перетаскивания.                                                          |

## Возвращаемые значение

| Property      | Type                         | Description                                                 |
|---------------|------------------------------|-------------------------------------------------------------|
| `x`           | `Ref<number>`                | Координата `X` перетаскиваемого элемента.                   |
| `y`           | `Ref<number>`                | Координата `Y` перетаскиваемого элемента.                   |
| `style`       | `ComputedRef<CSSProperties>` | Вычисляемые стили с динамическим свойствами `left` и `top`. |
| `isDragging`  | `Ref<boolean>`               | Состояние перетаскивания.                                   |
