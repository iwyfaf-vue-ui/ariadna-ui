   Для каждого emit проверь:
   - Emit срабатывает в правильный момент.
   - Emit передаёт правильный payload (если есть).
   - Emit НЕ срабатывает когда условия не выполнены (например, disabled или уже закрыто).

## CSS-классы в тестах

При написании любых тестов для компонентов и composable:

- **Не хардкоди CSS-строки вручную** (например, `'ar-button--disabled'`, `'ar-dropdown-menu__item'`).
- **Используй свойства и методы экземпляра `*SelectorTestData`** соответствующего компонента:
   - Для получения класса без точки: `defaultMock.getSelectorWithoutDot(defaultMock.someEl)`
   - Для модификаторов: `defaultMock.someModifier`
   - Для динамических модификаторов с параметром: `defaultMock.getSomeLevelModifier(n)`
- **Исключение**: внутри `vi.hoisted()` импорты недоступны — там допустимо использовать строковый литерал с базовым CSS-классом компонента.
- **Не импортируй `E*PropsDefault` enum только ради CSS-строк** — если все значения уже доступны через `*SelectorTestData`, импорт enum не нужен.
